==================================================
네이버 붙여넣기 안내 (메모장으로 여세요)
==================================================

순서: ① 제목 → ② 본문 → ③ 서식 → ④ 사진 → ⑤ 지도 → ⑥ 태그 → ⑦ 발행 전 확인


① 제목 — 제목 칸에 붙여넣기
--------------------------------------------------
게임 그래픽 디자이너 되려면 뭐부터? 갈래 다섯을 먼저 고르세요


② 본문
--------------------------------------------------
네이버_본문.txt 를 메모장으로 열어 전체 복사(Ctrl+A → Ctrl+C) → 본문에 붙여넣기


③ 서식 적용 (가독성에 가장 큰 영향)
--------------------------------------------------
- 본문 전체 선택 → 글자 크기 15
- [소제목] 으로 시작하는 줄 → 툴바 '소제목' 서식 → "[소제목] " 글자 삭제
  (소제목 서식이 없으면: 굵게 + 글자 크기 19)
- [인용구] 로 시작하는 요약 부분 → 툴바 '인용구' → '라인' 스타일 → 왼쪽 정렬 → "[인용구] " 글자 삭제


④ 이미지 — 안내 줄 자리에 올리고, 사진 아래 '사진 설명' 칸에 입력 → 안내 줄 삭제
--------------------------------------------------
[생성 이미지]
   1) 네이버_썸네일.png
      → 사진 설명: 게임 그래픽 디자이너는 다섯 갈래예요. 툴보다 갈래를 먼저 골라야 해요
   2) 공통_five-tracks.png
      → 사진 설명: 다섯 갈래가 각각 뭘 만들고 어떤 툴로 시작하는지 한 장에 모았어요
   3) 공통_choose-order.png
      → 사진 설명: 갈래를 고르는 세 단계예요. 장면 멈추기, 툴 2주 써 보기, 계속 만들고 싶은지 보기
   4) 공통_paths.png
      → 사진 설명: 고등학생과 성인, 두 길이 어디서 갈라지고 어디로 이어지는지 그렸어요




⑤ 홈페이지 링크 카드 · 지도
--------------------------------------------------
"▶ 게임학원 홈페이지: http://…" 줄의 주소 부분만 복사 → 바로 아래 빈 줄에 붙여넣고 Enter → 링크 카드(미리보기)가 생기면 성공
(카드가 생기지 않아도 글자 링크로 동작합니다)
맨 아래 [지도] 줄 자리 → 툴바 '장소' → "SBS아카데미게임학원 대전점" 검색 → 추가 → [지도] 줄 삭제


⑥ 태그 — 태그 칸에 붙여넣기 (한 덩어리로 들어가면 하나씩 입력)
--------------------------------------------------
#게임그래픽디자이너 #게임그래픽 #게임그래픽학과 #게임원화 #3D모델링 #게임이펙트 #게임UI #포트폴리오전형 #게임학과입시 #대전게임학원


⑦ 발행 전 확인 — 아래는 '지우면 안 되는 본문'입니다
--------------------------------------------------
[ ] 소제목 "… (가상 사례)" 와 바로 아래 고지 문장이 남아 있다
[ ] "참고 자료" 목록이 연락처 위에 남아 있다
[ ] 연락처 아래에 지도가 들어갔다
[ ] 본문에 "[" 로 시작하는 안내 표시가 남아 있지 않다 (Ctrl+F 로 "[" 검색)
