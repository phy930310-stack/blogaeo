# 작업 보고서 — 2026-11-02_게임-3D-애니메이터-되는-법 (티스토리 전용)

## 1. 질문 지도
- 대표 키워드: 3D 애니메이션 — 새 묶음 "게임 3D 애니메이터 되는 법 (리깅·애니메이션·포트폴리오)". 포함 키워드 리깅(800)·3D애니메이션(280)·3D애니메이션학원(60)·3D모션그래픽(50)·3D애니메이터(40)·리깅학원(10)·3D모션학원(10)·3D모션그래픽학원(10)·3D모션그래픽취업(10)·대전애니메이션학원(15). 리깅(800)은 3D 모델링 묶음에도 들어 있으나 그 글은 리깅을 다루지 않아 이 글이 답한다.
- 핵심 질문: 게임 3D 애니메이터는 무슨 일을 하고, 리깅과 무엇이 다르며, 무엇부터 배워야 하나?
- 하위 질문
  1. 애니메이터·리거·테크니컬 애니메이터는 각각 무슨 일을 하고 2026년 10월 공고는 무엇을 요구했나?
  2. 리깅과 애니메이션은 무엇이 다른가? (모델링→리깅→애니메이션→엔진 4단계, 유니티 Animator Controller·언리얼 Control Rig)
  3. 무엇부터 어떤 순서로 배우나? (원리→툴 하나→리깅 기초→인게임 동작 세트→엔진 구현. 모델링은 구조 이해 수준)
  4. 포트폴리오(릴 영상)는 어떻게 구성하나? (60~90초, 넣을 것/뺄 것, 맡은 범위 표기)
  5. 고등학생·비전공 성인은 어디서 시작하나? (포트폴리오·면접 전형 / 학원 애니메이션 과정·국비 3과정, 상담 → 과정 확인 → 카드)
- 후속 질문: 게임 3D 모델링 입문(10-13) / 게임 그래픽 디자이너 5개 직군(10-31, /24) / 게임회사 취업 준비(10-03). 수시 2차 면접전형(10-30, /23)은 본문에서 연결.
- 기존 글과의 분담: 10-13 3D 모델링 글은 모델링 툴·제작 6단계·첫 작품. 이 글은 '움직임'(리깅·애니메이션·엔진·릴 영상)만 다루고 모델링은 그 글로 넘겼다. 같은 문장·같은 표 없음.
- 포지셔닝: 고등학생 안내는 포트폴리오·면접 전형, 국비 안내 순서는 "상담 → 과정 확인 → 카드 신청". 애니메이션(2D·3D) 과정이 있다는 사실만 쓰고 커리큘럼·강사·수강료·취업률은 쓰지 않았다. 국비 과정은 게임그래픽·게임프로그래밍(유니티)·웹툰 세 가지로만 표기.

## 7. 발행 전 확인
- 스마일게이트 리깅 공고의 자격 요건 세부(3ds Max bone·biped·skin, 해부학, 신입 과제 테스트)와 크래프톤 TA 공고 요건은 검색 요약이므로 공고 원문 대조 권장. 본문 표 3열과 Q1 두 번째·세 번째 문단이 해당.
- 오토데스크 교육용 플랜 조건(1년·갱신·대상)은 공식 페이지가 403이라 검색 요약 기준. 본문은 "나라마다 달라 공식 페이지에서 확인"으로 완충.
- 애니메이션(2D·3D) 과정의 세부(툴·기간)는 쓰지 않았다. 과정 구성이 본문의 "3ds Max 중심" 표현과 맞는지 사용자 확인.
- 학원 광고 표시 문구(등록번호·교습비)는 사용자가 직접 삽입.
- 내부 링크는 티스토리 주소가 확인된 /23(수시 2차)·/24(게임 그래픽 디자이너)만 걸었다. 3D 모델링·게임회사 취업 준비 글은 제목만 언급.
