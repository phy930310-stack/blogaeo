게임 QA는 게임이 기획대로 움직이는지 테스트 케이스로 확인하고 찾은 버그를 재현 절차와 함께 기록해 기획자·개발자에게 넘기는 직군입니다. 신입 공고는 대부분 학력과 경력을 묻지 않습니다. 대신 버그 기술서나 테스트 케이스처럼 직접 쓴 문서로 역량을 봅니다.

경력 없이 시작하려면 공고가 요구하는 문서 세 가지를 먼저 만들어 두는 것이 순서입니다. 버그 리포트 샘플, 테스트 케이스 문서, 게임 플레이 목록입니다. 아래에서 QA가 하는 일, 신입 공고 요건, 지원 전 준비물, 기획·개발로 이어지는 길을 차례로 정리합니다. 고등학생과 비전공 성인이 지금 할 수 있는 것도 마지막에 적었습니다.

기준: 넥슨네트웍스 게임QA 채용연계형 인턴 공고(2026년 1월·8월), NC소프트 PC온라인 게임QA 신입 공고, 엔씨큐에이 게임QA 공고(2025년 4월 마감), 게임잡 QA 직무 공고 목록(2026년 11월 4일 조회). 2026년 11월 4일 작성

핵심 요약

  • QA의 하루는 테스트 케이스 작성, 테스트 실행, 버그 리포트, 수정 뒤 재확인(회귀 테스트)으로 돌아갑니다. 게임을 즐기는 일이 아니라 기록하는 일입니다.
  • 신입 공고는 학력·경력 무관이 많고 버그 기술서, 게임 플레이 경력 목록, 테스트 케이스 작성 경험을 요구합니다. 프로그래밍과 ISTQB 자격증은 우대 조건입니다.
  • 지원 전에 하는 게임 하나를 골라 버그 리포트와 테스트 케이스를 직접 써 두면 됩니다. 게임 구조를 이해하려면 엔진으로 작은 게임을 만들어 보는 것이 가장 빠릅니다.

[이미지 업로드: 티스토리_썸네일.png / 대체텍스트: 게임 QA 되는 법 – 테스트 케이스로 확인하고 버그를 재현 절차와 함께 기록하는 직군, 신입 공고는 학력·경력 무관이 많고 버그 기술서·테스트 케이스 문서로 역량을 본다]

Q1. 게임 QA는 무슨 일을 하나요?

게임이 기획서대로 동작하는지 확인하고 아닌 부분을 기록해 고치게 만드는 일입니다. 넥슨네트웍스의 2026년 게임QA 인턴 공고는 담당 업무를 테스트 케이스 설계·실행과 기능·탐색·호환성 테스트로 적었습니다. 버그 트래킹, 로그 기반 테스트, 결함 관리, 자동화 도구로 테스트 환경을 고도화하는 일도 들어 있습니다.

하루 흐름은 네 단계로 돌아갑니다. 어떤 기능을 어떤 조건에서 확인할지 테스트 케이스로 적고 그대로 실행합니다. 기대와 다른 결과가 나오면 버그 리포트를 써서 담당 기획자·개발자에게 넘기고 수정된 빌드에서 같은 절차를 다시 돌려 고쳐졌는지 봅니다.

단계 하는 일 남기는 문서
테스트 설계 기획서를 읽고 확인 항목을 정함 테스트 케이스·체크리스트
테스트 실행 기능·탐색·호환성 테스트 실행 결과 기록
버그 보고 재현 절차와 기대·실제 결과 기록 버그 리포트(이슈 등록)
회귀 확인 수정 빌드에서 같은 절차 재실행 결과 보고서

[이미지 업로드: 공통_qa-cycle.png / 대체텍스트: 게임 QA 업무 4단계 – 1 테스트 설계(기획서를 읽고 테스트 케이스 작성), 2 테스트 실행(기능·탐색·호환성), 3 버그 보고(재현 절차·기대 결과·실제 결과), 4 회귀 확인(수정 빌드에서 재실행)]

테스트만 하는 자리는 아닙니다. NC소프트의 신입 게임QA 공고는 QA 일정과 위험 분석으로 테스트 전략을 세우는 일을 담당 업무에 넣었습니다. 개발 중인 게임의 기획을 검토하는 일과 결과 보고서를 쓰는 일도 들어 있습니다. 그래서 공고마다 "기획서나 구현물로 작동 순서를 파악할 수 있는 사람"을 찾습니다.

Q2. 신입 QA 공고는 무엇을 요구하나요?

학력과 경력보다 문서와 경험을 봅니다. 넥슨네트웍스 2026년 상반기 인턴 공고는 나이·전공·경력에 제한을 두지 않았고 전형은 서류·인성검사·실무진 면접이었습니다. NC소프트 신입 공고도 학력 무관에 경력 0~2년이고 게임잡 QA 목록에 올라온 공고는 대부분 학력 무관입니다.

대신 제출 서류가 다릅니다. 엔씨큐에이 게임QA 공고는 자기소개서와 함께 게임 플레이 경력 목록과 버그 기술서를 필수 서류로 받았습니다. 넥슨네트웍스는 "게임 로그와 중요 결함 사례를 학습해 개선점을 찾을 수 있는 사람"을 지원 자격으로 적었습니다.

우대 조건은 세 묶음입니다. 소프트웨어 전공이나 프로그래밍(C/C++/C#, Java, Python)이 하나, ISTQB 같은 테스팅 자격증이 둘입니다. 테스트 자동화와 이슈 관리 도구 사용 경험이 셋입니다. 스마일게이트의 Test Engineer 신입 공고처럼 1년 계약직으로 시작하는 자리도 많습니다.

[이미지 업로드: 공통_hiring-reqs.png / 대체텍스트: 신입 게임 QA 공고가 보는 것 – 필수: 학력·경력 무관이 많음, 버그 기술서·게임 플레이 경력 목록 제출, 기획서로 작동 순서 파악 / 우대: 프로그래밍(C/C++/C#·Java·Python), ISTQB 자격증, 테스트 자동화·이슈 관리 도구 경험. 넥슨네트웍스·NC소프트·엔씨큐에이·스마일게이트 공고 기준]

Q3. 지원 전에 무엇을 만들어 두어야 하나요?

버그 리포트 샘플, 테스트 케이스 문서, 게임 플레이 목록 세 가지입니다. 셋 다 지금 하는 게임 하나로 만들 수 있고 공고가 요구하는 버그 기술서와 테스트 케이스 작성 경험에 그대로 대응합니다. 포트폴리오를 따로 만들 필요 없이 이 문서들이 포트폴리오입니다.

버그 리포트는 다른 사람이 똑같이 재현할 수 있게 씁니다. 제목, 환경(기기·OS·빌드 버전), 재현 절차, 기대 결과, 실제 결과, 발생 빈도, 첨부(스크린샷·영상) 순서가 기본입니다. "가끔 멈춘다"처럼 느낌으로 적으면 개발자가 원인을 찾을 수 없습니다.

[이미지 업로드: 공통_bug-report.png / 대체텍스트: 버그 리포트 7항목 – 제목, 환경(기기·OS·빌드), 재현 절차(번호 순서), 기대 결과, 실제 결과, 발생 빈도, 첨부(스크린샷·영상). 다른 사람이 똑같이 재현할 수 있게 쓴다]

테스트 케이스는 기능 하나를 골라 확인 항목을 표로 적습니다. 인벤토리라면 아이템 획득 시 수량, 사용 뒤 수량, 가득 찼을 때 새 아이템 처리처럼 조건을 나눠 기대 결과를 미리 씁니다. 20~30개 항목이면 문서 구조를 보여 주기에 충분합니다.

자격증은 필수가 아니지만 ISTQB 기초 레벨(CTFL)은 응시 제한이 없어 비전공자도 바로 볼 수 있습니다. 한국에서는 KSTQB가 시험을 주관합니다. 시험 일정과 응시료는 KSTQB 공식 안내에서 확인하는 편이 정확합니다.

Q4. QA에서 기획이나 개발로 옮길 수 있나요?

QA 안에서 올라가는 길과 다른 직군으로 옮기는 길이 있지만 어느 쪽도 자동으로 열리지는 않습니다. QA 안에서는 기능 QA에서 시작해 자동화·테크니컬 QA나 QA 리드로 가는 경로가 공고에 나타납니다. 자동화 쪽은 프로그래밍이 필요해서 우대 조건에 코딩이 들어갑니다.

기획 쪽으로는 업무 자체가 발판이 됩니다. NC소프트 공고처럼 QA가 기획 검토와 기획 데이터 검수를 맡는 회사에서는 기획서를 가장 많이 읽는 사람이 QA입니다. 다만 직군 전환은 회사 제도와 공석에 달려 있어 QA 경력만으로 보장되지 않습니다.

그래서 옮길 생각이 있다면 QA로 일하면서 목표 직군의 결과물을 따로 만들어야 합니다. 기획이면 역기획서, 개발이면 엔진으로 만든 작은 게임입니다. 이 부분은 「게임회사 취업 준비」 글의 직군별 준비물에 정리해 두었습니다.

Q5. 고등학생과 비전공 성인은 지금 무엇을 하면 되나요?

고등학생은 하는 게임 하나로 버그 리포트 3개와 테스트 케이스 20개를 써 보는 것부터입니다. 돈도 장비도 들지 않고 공고가 보는 역량이 그대로 드러납니다. 진학은 게임학과의 포트폴리오·면접 전형으로 가면 되고 테스트 문서와 엔진으로 만든 작은 게임이 그 포트폴리오가 됩니다.

비전공 성인은 문서 세 가지에 게임 엔진 기초를 더하면 됩니다. 공고가 "구현물로 작동 순서를 파악하는 사람"을 찾기 때문에 게임이 어떻게 만들어지는지 알아야 테스트 케이스가 깊어집니다. 유니티로 작은 게임 하나를 끝까지 만들어 보면 빌드, 로그, 버전이라는 말이 몸에 붙습니다.

[이미지 업로드: 공통_start-steps.png / 대체텍스트: 경력 없이 게임 QA 시작하는 순서 4단계 – 1 하는 게임 하나 고르기, 2 버그 리포트 3개·테스트 케이스 20개 쓰기, 3 게임 엔진으로 작은 게임 하나 만들기(빌드·로그 이해), 4 공고의 제출 서류에 맞춰 지원]

SBS아카데미게임학원 대전점에는 QA 전용 과정이 없습니다. 대신 게임프로그래밍(유니티) 과정과 게임기획 과정이 기획서를 읽고 구현물의 작동 순서를 파악하는 힘을 기르는 쪽이라 QA 준비와 겹칩니다. 국비로 들을 생각이면 상담에서 과정 구성을 확인한 뒤 고용24에서 과정명을 찾고 국민내일배움카드를 신청하는 순서가 맞습니다.

사무직을 그만두고 게임 QA 공고를 보고 온 20대 후반 (가상 사례)

아래는 상담에서 자주 나오는 고민을 재구성한 가상 사례입니다.

상황 — 사무직 2년 차에 퇴사한 20대 후반입니다. 게임을 오래 했고 게임 QA 공고에 학력·경력 무관이 많은 것을 보고 상담을 신청했습니다.

고민 — "게임을 많이 한 것 말고는 보여 줄 게 없는데 서류에 뭘 내야 하나요? 코딩을 모르면 QA도 못 하나요?"

확인한 것 — 공고가 요구하는 버그 기술서와 테스트 케이스를 한 번도 써 본 적이 없었습니다. 코딩은 우대 조건이지 필수가 아니었지만 빌드·로그 같은 개발 용어를 전혀 몰랐습니다.

세운 계획 — 지금 하는 모바일 게임으로 버그 리포트 3개와 인벤토리 테스트 케이스 20개를 2주 안에 쓰기로 했습니다. 그다음 게임 구조를 이해하기 위해 유니티 과정 구성을 상담에서 확인하고 고용24에서 과정명을 찾아 카드 신청 여부를 정하기로 했습니다. 지원은 계약직 공고부터 넣기로 했습니다.

자주 묻는 질문

Q. 게임을 잘해야 QA가 될 수 있나요?

실력보다 폭과 기록이 중요합니다. 공고는 "게임을 폭넓고 깊이 즐기는 사람"이나 특정 장르 플레이 경험을 요구하지 대회 성적을 요구하지 않습니다. 여러 장르를 해 보고 어떤 게임을 얼마나 했는지 목록으로 정리해 두는 것이 실력보다 먼저입니다.

Q. 계약직 QA로 시작해도 괜찮나요?

신입 QA 공고는 계약직과 채용연계형 인턴이 많습니다. 넥슨네트웍스 인턴은 6개월 뒤 평가를 거쳐 정규직 전환 대상이 되고 스마일게이트 Test Engineer는 1년 계약직으로 뽑았습니다. 전환 조건은 회사마다 다르므로 공고의 계약 기간과 전환 여부를 확인하고 지원하면 됩니다.
