## 1. 질문 지도
- 대표 키워드: 게임 QA — 새 묶음 "게임 QA 되는 법 (업무·신입 공고 요건·준비물)". 포함 키워드 게임QA(220)·게임QA학원(15)·게임QA취업(10), 합산 245. 유형 취업 허브. (keywords/clusters.csv 행 추가는 본 세션이 수행)
- 핵심 질문: 게임 QA는 무슨 일을 하고, 경력 없이 어떻게 시작하나?
- 하위 질문
  1. 게임 QA는 무슨 일을 하나? (테스트 설계 → 실행 → 버그 보고 → 회귀 확인 4단계, 표 1 + 인포그래픽. 넥슨네트웍스·NC소프트 공고의 담당 업무)
  2. 신입 공고는 무엇을 요구하나? (학력·경력 무관, 버그 기술서·게임 플레이 경력 목록 제출, 지원 자격 문구, 우대 3묶음, 계약직·인턴)
  3. 지원 전에 무엇을 만들어 두나? (버그 리포트 7항목, 테스트 케이스 20~30항목, 플레이 목록, ISTQB CTFL 응시 제한 없음)
  4. QA에서 기획·개발로 옮길 수 있나? (QA 내부 경로, 기획 검토 업무가 발판, 전환은 보장 아님 → 목표 직군 결과물 별도 준비)
  5. 고등학생과 비전공 성인은 지금 무엇을 하나? (게임 하나로 문서 쓰기, 엔진으로 작은 게임, 포트폴리오·면접 전형, 학원 과정 연결 + 국비 순서)
- 후속 질문: 게임회사 취업 준비(10-03, 직군별 준비물) / 유니티 입문(10-19) / 대전 국비지원 교육(10-19).
- 기존 글과의 분담: 10-03 글은 5개 직군 개관에서 QA를 한 줄(테스트 케이스·버그 리포트 예시)로 언급. 이 글은 QA 실무 4단계, 실제 공고의 요건·제출 서류, 버그 리포트 항목, 전환 경로를 새로 다뤘다. 직군별 준비물은 반복하지 않고 제목만 언급해 연결했다.
- 포지셔닝: 학원에 QA 전용 과정이 없음을 Q5에 명시. 게임프로그래밍(유니티)·게임기획 과정을 "기획서를 읽고 구현물의 작동 순서를 파악하는 힘"이라는 공고 문구와 연결(2곳 + 배너). 국비 순서 "상담 → 과정 확인 → 카드 신청". 고등학생 진학은 포트폴리오·면접 전형. 연봉·취업률·합격률·전환율 수치 없음. 강사진·수강료 없음.
- 문체: 최근 티스토리 원고(10-31~11-03)와 같은 합쇼체. 이미지 문구는 해요체.

## 7. 발행 전 확인
- 넥슨네트웍스 8월 인턴 공고와 NC소프트 신입 공고는 전재본(삼육대 블로그·게임클래스)으로 확인했다. NC소프트 공고는 게시 연도가 없어 본문에 연도를 쓰지 않았다 → 넥슨 커리어·NC 채용 페이지 원문 대조 권장(Q1 둘째·넷째 문단, Q2 첫 문단, Q4 둘째 문단).
- ISTQB 기초 레벨 "응시 제한 없음"은 검색 요약 기준 → KSTQB 공식 안내 대조 권장(Q3 마지막 문단).
- "QA 안에서 기능 QA → 자동화·테크니컬 QA나 QA 리드로 가는 경로가 공고에 나타난다"는 스마일게이트 시니어 개발 QA, 넥슨 TQA 등 공고 제목에서 유추한 서술 → 과하다고 보시면 "회사에 따라"로 완화.
- Q5의 "게임프로그래밍(유니티) 과정과 게임기획 과정이 … QA 준비와 겹친다"는 과정 내용에 기획서 읽기·구현물 분석이 실제로 포함되는지 사용자 확인.
- 가상 사례의 "사무직 2년 차 퇴사" 설정과 "계약직 공고부터 넣기로" 계획이 상담 방침과 맞는지 확인.
- 학원 광고 표시 문구(등록번호·교습비)는 사용자가 직접 삽입.
- 내부 링크: 게임회사 취업 준비(10-03)·유니티 입문(10-19)·대전 국비지원 교육(10-19)은 티스토리 주소가 저장소에 없어 제목만 언급 → 주소를 알면 링크 추가.
