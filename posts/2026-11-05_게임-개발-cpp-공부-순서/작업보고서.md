# 작업 보고서 — 2026-11-05_게임-개발-cpp-공부-순서 (티스토리 전용)

## 1. 질문 지도
- 대표 키워드: 게임 개발 C++ 공부 순서 (포함: C++, C++프로그래밍 / 보조: C++기초, C++학원, 언리얼 C++). 유형 취업. (keywords/used.csv·clusters.csv 갱신은 본 세션이 수행)
- 핵심 질문: 게임 개발자가 되려면 C++를 어디까지, 어떤 순서로 공부해야 하나?
- 하위 질문
  1. 게임 개발에 왜 아직 C++인가? (언리얼 5.8 공식 문서 "C++ 경험 가정", 게임잡 신입 클라이언트·서버 공고 키워드 C++, 예외로 기어세컨드 C#·유니티 공고)
  2. 처음이면 C++부터인가 C#부터인가? (목표별 표 + 인포그래픽. 넥슨 넥토리얼 "C++ 또는 C#". 엔진 선택·블루프린트→C++ 순서는 기존 글로 넘김)
  3. C++ 기초 공부 순서 5단계 (변수·제어문·함수 → 포인터·참조·메모리 → 클래스·상속·가상함수 → STL → 스마트 포인터·RAII, 단계별 게임 사용처 한 줄, cppreference RAII 정의)
  4. 기초가 끝났는지 확인하는 과제 3개 (콘솔 텍스트 게임 → SFML/SDL 2D 게임 → 언리얼 C++ 클래스 한 개: 공식 퀵스타트 FloatingActor, VS 2022 17.14+/2026)
  5. 신입 공고·코딩 테스트는 C++로 무엇을 보나 (하이퍼센트 1차 면접 간단 코딩 테스트, 이스트게임즈 서류→실무→최종 + 포트폴리오, 엔씨 2026 공채 온라인 코딩 테스트, 넥슨 넥토리얼 코딩 테스트 폐지→AI 평가)
  6. 국비로 배울 수 있나 (고용24 검색, 대전점 게임프로그래밍 과정 유니티&언리얼·국비는 유니티 기준, 상담 → 과정 확인 → 카드 신청, 훈련비 미기재)
- 후속 질문: 게임 프로그래머 되는 법(10-04) / 언리얼 엔진 입문(11-01, /25 링크) / 유니티 입문(10-19)
- 기존 글과의 분담: 10-04 글 Q2(C#·C++ 선택 일반론)·Q3(5단계 일반 로드맵)과 11-01 글 Q3(블루프린트→C++)·Q5(언리얼 공고)는 요약·제목 언급으로만 연결. 이 글은 C++ 자체의 단계·확인 과제·C++ 기준의 공고 요구를 새로 다뤘다. 하이퍼센트 공고는 11-01 글에서도 썼지만 이번에는 키워드·코딩 테스트 관점으로 인용.
- 포지셔닝: 학원 언급 2곳(Q6, 배너). 국비 순서 "상담 → 과정 확인 → 카드 신청". C++·언리얼 비중은 상담에서 확인으로 처리. 연봉·취업률·합격률·강사진·수강료 없음. 광고 표시 문구 없음.
- 문체: 11-04 QA 글과 같은 합쇼체. 이미지 문구는 해요체.
