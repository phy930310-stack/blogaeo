게임 개발용 C++는 기초 문법, 포인터·메모리, 클래스·가상함수, STL, 스마트 포인터·RAII 다섯 단계 순서로 공부하면 됩니다. 단계가 끝날 때마다 콘솔 게임, 2D 라이브러리 게임, 언리얼 C++ 클래스 한 개로 손에 익었는지 확인합니다. 언리얼 엔진과 국내 게임사의 클라이언트·서버 공고가 아직 C++를 요구하기 때문입니다.

문법책을 끝까지 읽는 것과 게임을 만들 수 있는 것은 다릅니다. 그래서 이 글은 어디까지 공부할지와 어떤 순서로 공부할지를 나눠 답합니다. 처음이면 C++와 C# 중 무엇부터인지, 신입 공고와 코딩 테스트가 C++로 무엇을 보는지, 국비로 배울 수 있는지도 정리했습니다.

기준: 언리얼 엔진 5.8 공식 문서(C++ 프로그래밍·C++ 퀵스타트·Visual Studio 설정), ISO C++·cppreference 표준 현황, 게임잡 신입 공고(2026년 8~9월 등록), 넥슨 넥토리얼 2026 모집 안내, 한국콘텐츠진흥원 게임국가기술자격검정 안내. 2026년 11월 5일 작성

핵심 요약

  • 언리얼 엔진 공식 문서는 C++ 섹션을 "C++ 경험이 있다"는 전제로 씁니다. 게임잡의 신입 클라이언트·서버 공고 키워드에도 C++가 들어 있습니다.
  • 목표가 언리얼·PC·콘솔·서버면 C++, 모바일·유니티면 C#부터입니다. 넥슨 넥토리얼 2026은 "C++ 또는 C#"을 요구했습니다.
  • 기초 다섯 단계가 끝났는지는 콘솔 텍스트 게임, SFML·SDL 2D 게임, 언리얼 C++ 클래스 한 개로 확인합니다. 세 번째까지 되면 공고가 요구하는 결과물이 생깁니다.

Q1. 게임 개발에 왜 아직 C++입니까?

게임 엔진과 게임의 핵심 코드가 C++로 쓰여 있기 때문입니다. 언리얼 엔진 5.8 공식 문서는 C++ 프로그래밍 섹션을 "C++에 어느 정도 경험이 있다고 가정"하고 씁니다. C++로 새 클래스를 만들면 Visual Studio나 Xcode로 컴파일한 뒤 에디터에 바로 반영됩니다.

공고도 같습니다. 성남의 PC 게임 개발사 하이퍼센트는 2026년 9월 「언리얼 개발자 신입 채용」을 올렸습니다. 키워드는 C++·UnrealEngine·OOP·최적화입니다(게임잡). 이스트게임즈가 2026년 8월 올린 신입 클라이언트 공고와 신입 서버 공고에도 C++가 키워드로 들어 있습니다.

다만 모든 게임 공고가 C++는 아닙니다. 모바일 게임사 기어세컨드의 2026년 9월 클라이언트 공고는 C#·유니티가 중심입니다. 제출물도 "본인의 역량을 표현할 수 있는 C# 코드"입니다. 그래서 다음 질문이 목표별 언어 선택입니다.

Q2. 처음이면 C++부터입니까, C#부터입니까?

가려는 자리가 정합니다. 언리얼·PC·콘솔·엔진·서버가 목표면 C++, 모바일·유니티가 목표면 C#부터입니다. 아직 목표가 없으면 유니티·C#으로 작은 게임을 먼저 끝내고 C++로 넘어가는 쪽이 막히는 곳이 적습니다.

목표 먼저 잡을 언어 확인한 공고
언리얼·PC·콘솔 C++ 하이퍼센트 언리얼 신입(C++)
모바일·유니티 C# 기어세컨드 클라이언트(C# 코드 제출)
서버·엔진 C++ 먼저(회사별 C#·Java 병행) 이스트게임즈 신입 서버(C++ 키워드)
아직 모름 둘 중 하나를 깊게 넥슨 넥토리얼 "C++ 또는 C#"

넥슨 넥토리얼 2026은 게임 프로그래머 채용형 인턴십으로 2026년 8월 25일부터 9월 7일까지 접수했습니다. 지원 자격에 "C++ 또는 C#을 이용한 개발이 가능한 분"을 적었고 업무는 클라이언트·서버·엔진 개발입니다. 큰 회사일수록 언어 하나를 깊게 아는 사람을 찾고 엔진은 입사 뒤에 맞춥니다.

둘 중 하나를 깊게 익히면 다른 쪽으로 옮기는 데 오래 걸리지 않습니다. 엔진별 차이와 블루프린트 다음에 C++를 붙이는 순서는 「게임 프로그래머 되는 법」·「언리얼 엔진 입문」 글에 있습니다. 이 글은 C++를 고른 뒤 무엇을 어떤 순서로 공부하는지에 집중합니다.

Q3. C++ 기초는 어떤 순서로 공부합니까?

다섯 단계입니다. 앞 단계를 건너뛰면 뒤 단계가 이해되지 않는 순서라서 바꾸지 않는 편이 좋습니다. 각 단계가 게임에서 어디에 쓰이는지 한 줄씩 붙였습니다.

  1. 변수·제어문·함수 — 체력·점수 같은 값을 담고 조건과 반복으로 턴을 돌립니다. 모든 게임 규칙의 뼈대입니다.
  2. 포인터·참조·메모리 — 캐릭터 하나를 여러 시스템이 복사 없이 가리킵니다. 언리얼의 오브젝트 포인터가 여기서 나옵니다.
  3. 클래스·상속·가상함수 — 몬스터 공통 클래스를 만들고 종류별로 다르게 움직입니다. 언리얼의 액터·컴포넌트 계층이 이 구조입니다.
  4. STL 컨테이너·알고리즘 — vector·map으로 인벤토리와 적 목록을 관리하고 정렬·탐색을 씁니다. 코딩 테스트가 보는 자료구조가 여기입니다.
  5. 스마트 포인터·RAII — 메모리·파일·락 같은 자원을 객체 수명에 묶어 누수를 막습니다. 게임이 오래 켜져 있어도 안 터지게 하는 습관입니다.

[이미지 업로드: 공통_cpp-roadmap.png / 대체텍스트: 게임 개발 C++ 공부 순서 5단계 – 1 변수·제어문·함수(게임 규칙의 뼈대), 2 포인터·참조·메모리(오브젝트를 복사 없이 가리킴), 3 클래스·상속·가상함수(액터·컴포넌트 계층), 4 STL 컨테이너·알고리즘(인벤토리·적 목록, 코딩 테스트), 5 스마트 포인터·RAII(자원 누수 방지)]

RAII는 cppreference가 "먼저 얻어야 쓸 수 있는 자원의 생애를 객체의 수명에 묶는 C++ 기법"으로 설명합니다. std::unique_ptr·std::shared_ptr가 동적 메모리를, std::lock_guard가 뮤텍스를 그렇게 관리합니다. 언리얼 공식 문서의 C++ 섹션에도 컨테이너·오브젝트 포인터·델리게이트가 따로 있습니다.

단계마다 책 한 권을 다 읽을 필요는 없습니다. 그 단계 문법으로 작은 프로그램 하나가 돌아가면 다음으로 넘어갑니다. 정말 손에 익었는지는 아래 과제로 확인합니다.

Q4. 기초가 끝났는지 어떻게 확인합니까?

과제 세 개를 순서대로 만들어 보면 됩니다. 콘솔 텍스트 게임, SFML이나 SDL로 만든 2D 게임, 언리얼 C++ 클래스 한 개입니다. 세 번째까지 되면 신입 공고가 요구하는 "C++로 만든 결과물"이 생깁니다.

  1. 콘솔 텍스트 게임 — 턴제 전투나 텍스트 던전. 클래스로 캐릭터·몬스터를 나누고 vector로 인벤토리를 만들면 1~4단계가 확인됩니다.
  2. SFML·SDL 2D 게임 — 창을 띄우고 키 입력으로 스프라이트를 움직이는 벽돌 깨기나 슈팅. 엔진 없이 게임 루프를 직접 짜 봅니다.
  3. 언리얼 C++ 클래스 한 개 — 공식 C++ 퀵스타트대로 Actor를 상속한 클래스를 만들고 Tick에서 움직입니다.

SFML은 공식 튜토리얼(3.0)이 창·이벤트·키보드와 마우스 입력, 스프라이트·텍스트·뷰, 오디오를 순서대로 안내합니다. 시작은 CMake 프로젝트 템플릿을 권합니다. SDL3는 C로 쓰여 C++에서 그대로 쓰이고 zlib 라이선스라 무료입니다.

언리얼 공식 C++ 퀵스타트의 목표는 "공중에 떠서 계속 회전하는 큐브"입니다. Actor를 상속한 FloatingActor 클래스에 StaticMeshComponent를 붙이고 Tick 함수에서 위치와 회전을 바꿉니다. 이 한 개가 되면 클래스·포인터·컴포넌트가 엔진 안에서 어떻게 쓰이는지 보입니다.

[이미지 업로드: 공통_practice-steps.png / 대체텍스트: C++ 기초가 끝났는지 확인하는 과제 3단계 – 1 콘솔 텍스트 게임(클래스·vector로 턴제 전투), 2 SFML·SDL 2D 게임(창·입력·스프라이트, 게임 루프 직접 작성), 3 언리얼 C++ 클래스 한 개(Actor 상속, Tick에서 회전). 세 번째까지 되면 공고가 요구하는 C++ 결과물이 생긴다]

환경은 언리얼 5.8 문서 기준으로 Visual Studio 2022(17.14 이상) 또는 2026입니다. 설치할 때 "Game development with C++" 워크로드를 고르면 됩니다. 컴파일이 오래 걸리는 PC라면 1·2단계 과제를 충분히 한 뒤 언리얼로 넘어가는 편이 낫습니다.

Q5. 신입 공고와 코딩 테스트는 C++로 무엇을 봅니까?

자료구조·알고리즘 문제와 직접 만든 결과물 두 가지입니다. 코딩 테스트는 회사마다 있기도 없기도 하지만 포트폴리오는 확인한 공고 모두가 요구했습니다.

하이퍼센트 언리얼 신입 공고는 1차 실무진 면접에서 간단한 코딩 테스트와 직무 질문을 함께 봅니다. 제출 서류는 이력서·자기소개서·포트폴리오입니다. 이스트게임즈 신입 클라이언트·서버 공고는 서류, 실무 면접, 최종 면접 순서이고 제출물에 포트폴리오가 있습니다.

큰 회사는 갈립니다. 엔씨소프트 2026년 신입 공채(2025년 10월 접수)는 프로그래밍·AI 지원자에게 온라인 코딩 테스트를 추가로 치르게 했습니다(보도 기준). 넥슨 넥토리얼 2026은 코딩 테스트를 없애고 AI 면접과 AI 활용 역량 평가로 바꿨습니다.

그래서 준비는 두 갈래입니다. STL로 정렬·탐색·그래프 탐색 같은 기본 문제를 C++로 푸는 연습이 하나입니다. Q4의 과제 세 개를 깃허브 코드와 플레이 영상으로 정리하는 일이 둘입니다. 어느 방식이든 면접에서는 내가 쓴 코드를 설명할 수 있어야 합니다.

Q6. C++를 국비로 배울 수 있습니까?

고용24에서 'C++'나 '언리얼'로 검색하면 국민내일배움카드로 들을 수 있는 과정이 지역별로 나옵니다. 과정마다 C++ 비중과 선발 조건이 달라서 과정 페이지의 훈련 내용을 열어 봐야 합니다.

SBS아카데미게임학원 대전점의 게임프로그래밍 과정은 유니티와 언리얼을 모두 다룹니다. 고용24에 국가기간·전략산업직종훈련으로 등록된 국비 과정은 유니티 기준입니다. C++·언리얼 비중은 상담에서 과정 구성으로 확인해야 합니다.

순서는 상담 → 과정 확인 → 카드 신청입니다. 입과 전에 상담과 간단한 실기로 기초를 확인하므로 카드부터 만들면 과정에 따라 입과가 안 될 수 있습니다. 훈련비와 자부담은 고용24에서 과정명으로 확인하십시오.

C++ 책을 두 번 읽었는데 게임이 안 만들어지는 비전공 20대 중반 (가상 사례)

아래는 상담에서 자주 나오는 고민을 재구성한 가상 사례입니다.

상황 — 비전공으로 졸업한 20대 중반입니다. 독학으로 C++ 입문서를 두 번 읽었고 언리얼 신입 공고를 보고 상담을 신청했습니다.

고민 — "문법은 아는데 게임을 만들 줄 모릅니다. 언리얼로 바로 들어가도 되나요, 아니면 C++를 더 해야 하나요?"

확인한 것 — 클래스와 포인터까지는 설명할 수 있었지만 STL과 스마트 포인터는 이름만 알았습니다. 콘솔 게임 하나도 끝까지 만들어 본 적이 없었습니다. 관심 공고 세 건은 모두 C++·언리얼·포트폴리오를 적었습니다.

세운 계획 — 2주 안에 턴제 콘솔 전투 게임을 클래스와 vector로 만들기로 했습니다. 그다음 한 달은 SFML로 벽돌 깨기, 그 뒤 언리얼 C++ 퀵스타트로 Actor 하나를 만들기로 했습니다. 국비는 상담에서 과정 구성을 확인한 뒤 고용24에서 과정명을 찾아 카드 신청 여부를 정하기로 했습니다.

Q. C++ 자격증이 있습니까?

C++ 이름이 붙은 국가기술자격은 없습니다. 게임 분야는 한국콘텐츠진흥원이 시행하는 게임프로그래밍전문가가 있고 필기는 응시 자격 제한이 없습니다. 2026년 시험은 끝났으니 2027년 일정은 게임국가기술자격검정 누리집(kgq.or.kr)에서 확인하십시오. 확인한 신입 공고는 자격증 대신 포트폴리오와 코딩 테스트로 실력을 봤습니다.

Q. C++ 버전은 무엇을 기준으로 공부합니까?

현재 공식 표준은 C++23이고 C++26은 작업 중입니다(ISO C++·cppreference 현황). 입문 단계에서는 버전을 고를 필요가 없습니다. auto, 범위 기반 for, 스마트 포인터처럼 C++11 이후 문법을 쓰는 교재와 최신 Visual Studio면 충분합니다. 언리얼 5.8은 Visual Studio 2022 17.14 이상 또는 2026을 요구합니다.
