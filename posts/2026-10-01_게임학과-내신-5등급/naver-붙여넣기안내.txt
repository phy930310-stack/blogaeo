네이버 붙여넣기 안내 (이 파일은 메모장으로 여세요)
==================================================

순서: ① 제목 → ② 본문 → ③ 서식 → ④ 사진 → ⑤ 지도 → ⑥ 태그 → ⑦ 발행 전 확인


① 제목 — 아래 한 줄을 제목 칸에 붙여넣기
--------------------------------------------------
게임학과, 내신 5등급이면 정말 어려울까요? 대전 게임학원 입시상담팀이 정리했어요


② 본문
--------------------------------------------------
naver.md 를 메모장으로 열어 전체 복사(Ctrl+A → Ctrl+C) → 본문에 붙여넣기


③ 서식 적용 (가독성에 가장 큰 영향)
--------------------------------------------------
- 본문 전체 선택 → 글자 크기 15
- [소제목] 으로 시작하는 줄 → 툴바 '소제목' 서식 적용 → "[소제목] " 글자 삭제
  (소제목 서식이 없으면: 굵게 + 글자 크기 19)
- [인용구] 3줄 요약 부분(아래 3줄 포함) → 툴바 '인용구' → '라인' 스타일 → 왼쪽 정렬
  → "[인용구] " 글자 삭제


④ 사진 — [이미지: …] 줄 자리에 사진을 올리고, 사진 아래 '사진 설명' 칸에 입력
--------------------------------------------------
   1) thumb-naver.png
      → 사진 설명: 내신 5등급, 게임학과 진학 가능성을 등급제·전형별로 정리했어요
   2) admission-types.png
      → 사진 설명: 게임학과 전형별 내신 반영 비중 비교 (2027학년도 기준)
   3) grade-compare.png
      → 사진 설명: 9등급제와 5등급제에서 5등급의 위치 비교
   4) roadmap.png
      → 사진 설명: 2026년 10월 기준, 학년별 게임학과 입시 준비 순서
   ※ 사진을 올린 뒤 [이미지: …] 줄은 삭제


⑤ 지도
--------------------------------------------------
맨 아래 [지도] 줄 자리 → 툴바 '장소' → "SBS아카데미게임학원 대전점" 검색 → 추가 → [지도] 줄 삭제


⑥ 태그 — 아래 한 줄을 태그 칸에 붙여넣기 (한 덩어리로 들어가면 하나씩 입력)
--------------------------------------------------
#게임학과 #게임학과입시 #게임학과내신 #내신5등급 #내신5등급제 #게임학과실기 #게임포트폴리오 #대전게임학원 #둔산동게임학원 #SBS아카데미게임학원대전점


⑦ 발행 전 확인 — 아래는 '지우면 안 되는 본문'입니다
--------------------------------------------------
[ ] 소제목 "상담에서 자주 만나는 상황이에요 (가상 사례)" 와
    바로 아래 문장 "아래는 상담에서 자주 나오는 고민을 재구성한 가상 사례예요." 가 남아 있다
[ ] "참고 자료" 목록이 연락처 위에 남아 있다
[ ] 연락처(주소·전화·운영시간) 아래에 지도가 들어갔다
[ ] 본문에 "[" 로 시작하는 안내 표시가 하나도 남아 있지 않다 (Ctrl+F 로 "[" 검색)
