## 1. 질문 지도
- 대표 키워드: 게임 C# 공부 — 새 묶음 "게임 개발 C# 공부 순서". 포함 키워드 C#(430)·C#프로그래밍입문(15)·C#교육(15)·C#학원(10)·C#국비지원(10)·C#배우기(10)·C#강좌(10)·C#기초(10)·C#강의(10)·C#인강(10)·C#인터넷강의(10)·유니티공부(15)·유니티개발(20)·유니티개발자(15), 합산 590. 모두 backlog에서 어느 묶음에도 없던 키워드(유니티엔진·유니티학원은 10-04 프로그래머 묶음, 유니티자격증은 11-11 자격증 묶음에 있어 제외).
- 핵심 질문: 게임 개발용 C#은 무엇을 어떤 순서로 공부하고, 어디까지 하면 유니티 신입 공고에 낼 수 있는가?
- 하위 질문
  1. 게임 개발에서 C#은 어디에 쓰이나? (유니티 스크립트 언어, MonoBehaviour, 공고 키워드)
  2. C#과 C++ 중 무엇부터? (엔진·메모리 관리·확인한 공고, C++ 글로 연결)
  3. C# 기초는 어떤 순서로? (5단계, Microsoft Learn 자습서 6단원·Unity Learn Junior Programmer 12주)
  4. 유니티에서는 C#을 어떻게 다르게 쓰나? (시작점, C# 9.0, 코루틴, 매 프레임 할당, ScriptableObject)
  5. 기초가 끝났는지 어떻게 확인하나? (콘솔 텍스트 RPG → 유니티 미니게임 → 같은 게임 다시 짜기)
  6. 유니티 신입 공고는 C#을 어느 수준으로 보나? (게임잡 공고 3건의 제출물·지원 자격)
  7. 어디서 배우나? (독학 자료, 대전점 과정, 국비 순서)
- 후속 질문: 게임 개발 C++ 공부 순서(/29) / 게임 프로그래머 되는 법(/7) / 게임 만들기 처음 시작(/31)
- 기존 글과의 분담: 10-19 유니티 입문은 엔진(설치·에디터·무료 조건)과 "첫 게임에 필요한 C#은 변수~클래스" 수준까지만 다룸. 11-05 C++ 글은 C++ 5단계·SFML·언리얼 과제. 이 글은 C# 언어 자체(값·참조 형식, 컬렉션, 인터페이스, 델리게이트·코루틴), 유니티에서만 달라지는 규칙, C# 과제 3개, 유니티 공고 3건으로 내용이 겹치지 않게 함. Q2의 목표별 선택은 C++ 글 표와 겹치지 않게 '엔진·메모리 관리·공고' 기준 표로 짧게 쓰고 링크.
- 포지셔닝: 학원 언급은 Q7(게임프로그래밍 과정은 유니티와 언리얼, 국비 과정은 유니티 기준, C# 비중은 상담에서 확인, 순서 "상담 → 과정 확인 → 카드 신청")과 배너. 합격·취업 보장, 수강료, 강사진 없음. 광고 표시 문구는 사용자가 직접 삽입.

## 7. 발행 전 확인
- **C# 최신 버전 표기**: Microsoft Learn 「What's new in C# 15」(ms.date 2026-11-10)가 "C# 15는 .NET 11 SDK에서 net11.0 프로젝트의 기본 언어 버전"이라고 적어 본문·이미지에 ".NET 11 SDK 기본 C# 15"로 썼다. 같은 날 확인한 「The history of C#」(10-21 갱신)에는 아직 C# 14가 마지막 항목이라 "C# 15 정식 릴리스"라는 표현은 쓰지 않았다. .NET 11 정식 출시일은 확인하지 않음.
- **Unity 버전**: 매뉴얼 '현재' 버전이 Unity 6.6(6000.6)이라 그 기준으로 씀. 대전점 수업이 쓰는 유니티 버전과 다를 수 있음(학원 버전은 본문에 쓰지 않음).
- **공부 순서 5단계와 확인 과제 3개**는 Microsoft Learn 자습서·Unity Learn 과정의 순서를 묶은 **편집 제안**이다(공식 커리큘럼 아님). 본문 Q3 첫 문단에 "게임 기준으로 묶었다"고 밝힘.
- **Q2 "아직 목표가 없으면 C#으로 작은 게임을 먼저"**, **"C++는 초반에 익힐 것이 더 많다"**: 11-05 C++ 글과 같은 조언(출처 문장 아님).
- **Q3 "Vector3도 구조체라 다른 변수에 담으면 값이 복사된다"**: 구조체 선언은 스크립트 레퍼런스로 확인, 복사 동작은 C# 값 형식의 일반 규칙을 풀어 쓴 것.
- **Q4 "최신 문법을 쓴 교재의 코드는 유니티에서 컴파일 오류가 날 수 있다"**: 매뉴얼의 "미지원 기능을 쓰면 컴파일 오류"에서 끌어낸 서술. "몬스터 능력치나 아이템 표를 ScriptableObject에 두면…"은 매뉴얼의 용도(에셋으로 저장해 런타임에 사용)를 예로 풀어 쓴 것.
- **Q4 코루틴 "오래 걸리는 계산을 넣으면 안 된다"**, **FAQ "여러 스레드가 필요한 작업에는 잡 시스템이나 Awaitable의 async/await"**: WebFetch 요약문으로 확인한 내용 → 매뉴얼 「Coroutines」 원문 문장과 한 번 대조 권장.
- **Q5 Unity Learn 프로토타입 목록**(자동차·탑다운·러너·클릭 게임 등)과 **12주**: WebFetch 요약으로 확인. 무료 여부는 쓰지 않음.
- **채용 공고 3건**: 모두 채용 시 마감(2026-11-12 열람 시 게시 중). 기어세컨드는 본문이 이미지라 키워드·제출 서류·전형만 인용. 스콘은 게임 회사가 아니라 버추얼 캐릭터 솔루션 회사(게임잡 등록 공고)라고 본문에 밝힘. 데브캣은 경력 무관이지만 "실무 경험"을 지원 자격에 적어 그대로 옮김. 회사명(기어세컨드·스콘·데브캣·하이퍼센트·넥슨)은 본문에만 있고 태그에는 없음.
- **Q6 "두 건은 본인이 쓴 코드를 내라고 적었다"**: 기어세컨드(C# 코드 첨부)·데브캣(직접 작성한 소스코드 포함). 스콘은 "포트폴리오 필수"만 적음.
- **Q7 학원 서술**: "게임프로그래밍 과정은 유니티와 언리얼을 모두 다룬다", "국비 과정은 유니티 기준", "C# 비중과 진도는 상담에서 확인"이 실제 안내 방침과 맞는지.
- 가상 사례 설정(비전공 전문대 2학년, Update 함수 하나에 코드 집중)이 상담 방침과 맞는지.
- 내부 링크: /29·/7·/31·/4 걸었음. 유니티 입문(10-19)은 번호 미확인이라 제목만.
- 학원 광고 표시 문구(등록번호·교습비)는 사용자가 직접 삽입.
