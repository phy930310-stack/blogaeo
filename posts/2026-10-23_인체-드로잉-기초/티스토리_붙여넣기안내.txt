==================================================

순서: ⓪ 카테고리 → ① 제목 → ② 본문 → ③ 이미지 → ④ FAQ 코드 → ⑤ 태그 → ⑥ 발행 전 확인 → 발행


⓪ 카테고리 — 발행 설정 창에서 선택 (없으면 블로그 관리 → 카테고리 관리에서 먼저 생성)
--------------------------------------------------
포트폴리오·작품


① 제목 — 제목 칸에 붙여넣기
--------------------------------------------------
인체 드로잉 기초: 처음 그릴 것, 등신 비율 기준, 하루 30분 연습 루틴과 포트폴리오 연결


② 본문
--------------------------------------------------
글쓰기 → 우측 상단 '기본모드' → 'HTML' → 티스토리_본문.html 을 메모장으로 열어(오른쪽 클릭 → 연결 프로그램 → 메모장) 전체 복사(Ctrl+A, Ctrl+C) → 붙여넣기


③ 이미지 — 기본모드로 바꾼 뒤 [이미지 업로드: …] 자리에 업로드 → 이미지 클릭 → 대체텍스트 입력 → 안내 줄 삭제
--------------------------------------------------
[생성 이미지]
   1) 티스토리_썸네일.png
      → 대체텍스트: 인체 드로잉 기초 – 움직임·구조·비율 순서와 하루 30분 연습 루틴
   2) 공통_body-ratio.png
      → 대체텍스트: 인체 비율 등신 비교 – 2~3등신 SD 캐릭터, 7~7.5등신 실제 인체, 8등신 전후 일러스트 캐릭터
   3) 공통_daily-routine.png
      → 대체텍스트: 인체 드로잉 하루 30분 연습 루틴 – 크로키 10분, 마네킹 10분, 부분 연습 5분, 캐릭터 적용 5분




④ FAQ 코드 — 맨 마지막 작업! HTML 모드 → 코드 창 맨 아래(Ctrl+End)에 붙여넣기 → 이후 모드 전환 없이 바로 발행
--------------------------------------------------
<script type="application/ld+json">
{
  "@context": "https://schema.org",
  "@type": "FAQPage",
  "mainEntity": [
    {
      "@type": "Question",
      "name": "인체 드로잉을 하려면 해부학부터 공부해야 하나요?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "처음부터 해부학을 깊게 공부할 필요는 없습니다. 크로키로 움직임을, 마네킹으로 구조를, 등신으로 비율을 먼저 익힌 뒤 자주 막히는 부위부터 해부학을 찾아보는 순서가 부담이 적습니다."
      }
    },
    {
      "@type": "Question",
      "name": "인체 드로잉은 하루에 얼마나 연습해야 하나요?",
      "acceptedAnswer": {
        "@type": "Answer",
        "text": "정해진 기준은 없지만, 하루 30분이라도 매일 하는 것을 권합니다. 크로키 10분, 마네킹 10분, 부분 연습 5분, 내 캐릭터에 적용 5분처럼 나누면 짧은 시간에도 순서대로 연습할 수 있습니다."
      }
    }
  ]
}
</script>


⑤ 태그 — 태그 칸에 붙여넣기 (한 덩어리로 들어가면 하나씩 입력)
--------------------------------------------------
인체드로잉, 인체드로잉기초, 캐릭터드로잉, 크로키, 인체비율, 등신, 드로잉연습, 입시포트폴리오, 캐릭터일러스트


⑥ 발행 전 확인 — 아래는 '지우면 안 되는 본문'입니다
--------------------------------------------------

[ ] "참고 자료" 목록이 연락처 위에 남아 있다
[ ] [이미지 업로드: …] 안내 줄이 남아 있지 않다
[ ] 카테고리를 선택했다
