Q1. 유니티는 무엇이고 무료로 쓸 수 있습니까?

유니티는 2D와 3D 애플리케이션을 만드는 실시간 엔진입니다(Unity 6.6 매뉴얼). 화면, 물리, 소리, 입력을 에디터 하나에서 다루고 스크립트는 C#으로 씁니다. 개인과 작은 팀은 Unity Personal 플랜으로 돈을 내지 않고 시작합니다.

Enterprise 연 매출 2,500만 달러 초과 별도 견적

기준은 지난 12개월의 매출과 조달 자금입니다. 이 금액이 20만 달러를 넘으면 유료 구독 플랜을 골라야 합니다. 공부하거나 첫 게임을 만드는 단계에서는 닿지 않는 금액입니다.

Personal로 만든 게임은 웹, 데스크톱, 모바일, AR·VR용으로 내보낼 수 있습니다. 내려받을 때 신용카드가 필요 없고 시작 화면(스플래시)도 바꿀 수 있습니다. 플랜 안내에는 Personal이 게임과 엔터테인먼트 용도라고 적혀 있습니다.

조건과 가격은 바뀔 수 있습니다. 게임을 팔기 전에는 Unity 플랜 안내 페이지에서 원문을 다시 확인하십시오.

Q2. 어떤 버전을 설치합니까?

Unity Hub를 먼저 설치하고 Hub에서 에디터 버전을 고릅니다. 입문자는 따라 할 강의와 같은 버전을 받는 편이 좋습니다. Unity Essentials 과정을 따라 한다면 Unity 6.3 LTS가 맞습니다.

Unity Hub는 에디터 버전과 모듈을 내려받고 프로젝트와 라이선스를 관리하는 프로그램입니다. 매뉴얼도 Hub를 에디터를 설치하는 가장 좋은 방법으로 안내합니다. 템플릿과 학습 자료도 Hub 안에서 열 수 있습니다.

Unity 6은 LTS(장기 지원)와 업데이트 릴리스 두 가지로 나옵니다. LTS는 1년에 한 번 나오고 2년 동안 지원됩니다. Unity 6.3 LTS의 지원 기간은 2027년 12월까지입니다.

업데이트 릴리스는 1년에 여러 번 나오고 다음 릴리스가 나올 때까지 지원됩니다. 2026년 11월 현재 매뉴얼의 최신판은 Unity 6.6입니다. Unity Essentials 강의는 6.3, 6.0, 2022.3 버전 가운데 골라 볼 수 있습니다.

강의와 버전이 다르면 메뉴 위치와 화면이 달라 초반에 막히기 쉽습니다. 첫 프로젝트는 강의 버전에 맞추고 익숙해진 뒤 새 버전으로 올리는 순서를 권합니다.

Q3. 내 PC로 유니티가 돌아갑니까?

에디터는 메모리 8GB 이상을 권장합니다(Unity 6.6 시스템 요구 사항). 윈도우는 10 버전 21H1 이상, 맥은 macOS 13 벤투라 이상입니다. 그래픽카드는 DX10 이상이나 Vulkan을 지원하면 됩니다.

항목 윈도우 맥
운영체제 윈도우 10 21H1 이상 macOS 13 벤투라 이상
CPU SSE2 지원 x64, Arm64 애플 실리콘 M1 이상
그래픽 DX10·11·12 또는 Vulkan Metal 지원 GPU
메모리 8GB 이상 권장 8GB 이상 권장

Unity 6.6 매뉴얼 「System requirements」의 에디터 항목입니다(2026년 11월 13일 확인). 리눅스는 우분투 22.04와 24.04를 지원합니다.

Arm64 윈도우 PC는 윈도우 11 21H2 이상이어야 합니다. 인텔 맥도 목록에 있지만 지원 중단 예정(deprecated)으로 표시돼 있습니다. 새로 산다면 애플 실리콘 맥이 맞습니다.

매뉴얼은 프로젝트가 크고 복잡할수록 메모리가 더 필요하다고 적습니다. 빌드할 때는 작은 파일을 많이 읽고 쓰므로 입출력이 빠른 디스크를 권합니다. 입문 단계의 작은 2D·3D 프로젝트는 8GB 노트북으로 시작할 수 있습니다.

언리얼 엔진 5.8의 권장 메모리는 32GB입니다. 사양이 낮은 노트북으로 시작한다면 유니티 쪽이 부담이 적습니다. 언리얼 사양은 「언리얼 엔진 5 입문」 글에 있습니다.

Q4. 유니티는 어떤 순서로 시작합니까?

다섯 단계입니다. 설치, 에디터 창, 오브젝트와 컴포넌트, 스크립트, 작은 게임 완성 순서입니다. 매뉴얼도 설치한 다음 에디터 화면을 익히고 Unity Learn 튜토리얼을 하라고 안내합니다.

  1. Unity Hub 설치와 새 프로젝트 — Hub에서 에디터를 받고 2D나 3D 템플릿으로 프로젝트를 만듭니다.
  2. 에디터 창 다섯 개 — Scene 뷰에서 배치하고 Game 뷰로 실행 화면을 봅니다. Hierarchy는 오브젝트 목록, Inspector는 속성, Project는 파일 창입니다.
  3. 게임 오브젝트와 컴포넌트 — 캐릭터, 조명, 카메라가 모두 게임 오브젝트입니다. 기능은 컴포넌트를 붙여서 만듭니다.
  4. C# 스크립트 — 키 입력으로 움직이고 부딪히면 점수가 오르는 규칙을 코드로 씁니다.
  5. 작은 게임 하나 완성 — 시작 화면부터 게임 오버까지 만들고 실행 파일로 빌드합니다.

[이미지 업로드: 공통_unity-steps.png / 대체텍스트: 유니티 시작 5단계 – 1단계 Unity Hub 설치와 새 프로젝트, 2단계 에디터 창 다섯 개(Scene·Game·Hierarchy·Inspector·Project), 3단계 게임 오브젝트와 컴포넌트, 4단계 C# 스크립트(Start와 Update), 5단계 작은 게임 하나를 끝까지 만들어 빌드하기. 3단계가 유니티의 뼈대다]

3단계가 유니티의 뼈대입니다. 매뉴얼은 게임 오브젝트를 컴포넌트를 담는 그릇으로 설명합니다. 모든 게임 오브젝트에는 위치와 방향을 담는 Transform 컴포넌트가 붙어 있고 뗄 수 없습니다.

정육면체 오브젝트를 예로 들면 Mesh Filter와 Mesh Renderer가 표면을 그립니다. Box Collider는 물리 계산에 쓰는 부피를 맡습니다. 직접 쓴 C# 스크립트도 컴포넌트로 붙습니다.

Unity Essentials 과정도 비슷한 순서로 갑니다. 에디터, 3D, 오디오, 프로그래밍, 2D, 퍼블리싱 여섯 미션으로 나뉩니다. 첫 미션인 에디터 기초는 2시간 10분 분량이고 유니티 설치부터 시작합니다.

5단계에서는 첫 게임을 작게 잡아야 끝낼 수 있습니다. 범위를 정하는 방법은 「게임 만들기 처음 시작」 글에서 다룹니다.

Q5. C#은 어느 정도 알아야 유니티를 시작합니까?

변수, 조건문, 반복문, 함수, 클래스 다섯 가지면 첫 게임을 만들 수 있습니다. 문법책을 끝내고 시작할 필요는 없습니다. 나머지는 게임을 만들다가 필요할 때 익힙니다.

알아야 할 것 게임에서 쓰는 곳 예
변수 점수·체력·속도 담기 int score = 0;
조건문 충돌과 게임 오버 판정 if (hp <= 0)
반복문 적 여러 마리 처리 for, foreach
함수 점프·공격 같은 기능 묶기 void Jump()
클래스 스크립트 한 개의 틀 class Player

[이미지 업로드: 공통_csharp-basics.png / 대체텍스트: 유니티 첫 게임에 필요한 C# 다섯 가지 – 변수(점수·체력·속도 담기), 조건문(충돌과 게임 오버 판정), 반복문(적 여러 마리 처리), 함수(점프·공격 같은 기능 묶기), 클래스(스크립트 한 개의 틀). Start는 첫 Update 직전에 한 번, Update는 매 프레임 불린다]

새 스크립트를 만들면 Start와 Update 함수가 든 클래스가 생깁니다. Start는 첫 Update 직전에 한 번 불리고 Update는 매 프레임 불립니다. 입문 예제는 대부분 이 두 함수 안에 코드를 써넣습니다.

Unity Essentials 과정에도 프로그래밍 기초 미션이 있습니다. 과정 안내는 배우는 기술로 1단계 코드 이해와 1단계 스크립트 작성을 적었습니다. 코딩을 처음 하는 사람은 여기서 시작하면 됩니다.

취업이 목표면 다섯 가지에서 멈추면 안 됩니다. 컬렉션, 상속과 인터페이스, 이벤트와 코루틴까지 가야 공고가 요구하는 코드가 나옵니다. 그 순서는 「게임 개발 C# 공부 순서」 글에 정리했습니다.

Q6. 독학으로 충분합니까, 과정을 듣는 편이 낫습니까?

취미로 작은 게임을 만드는 목표면 독학으로 충분합니다. 기한 안에 취업 포트폴리오를 끝내야 하면 코드를 봐 줄 사람과 진도 관리가 있는 쪽이 빠릅니다. 목표와 기한을 먼저 정하고 고르면 됩니다.

기준 독학 과정 수강
맞는 목표 취미, 첫 게임 한 개 기한이 있는 취업 준비
배우는 곳 Unity Learn 강의 학원 과정, 국비 과정
막혔을 때 혼자 찾아서 해결 질문과 코드 피드백

독학은 Unity Learn에서 시작합니다. Unity Essentials는 유니티를 처음 쓰는 사람을 위한 과정이고 사전 경험이 필요 없으며 분량은 2주로 안내됩니다. 제공 언어는 영어와 스페인어라서 영어가 부담되면 브라우저 번역 기능을 켜고 보면 됩니다.

Unity는 Unity Learn을 무료 학습 자료로 소개합니다. 다음 과정인 Junior Programmer는 12주 분량이고 게임을 만들면서 C#을 배웁니다. 따라 만든 뒤에는 강의 없이 규칙 하나를 바꿔 다시 만들어 봐야 합니다.

SBS아카데미게임학원 대전점의 게임프로그래밍 과정은 유니티와 언리얼을 모두 다룹니다. 고용24에 국가기간·전략산업직종훈련으로 등록된 국비 과정은 유니티 기준입니다. 진도와 과정 구성은 상담에서 확인하는 것이 정확합니다.

국비 순서는 상담 → 과정 확인 → 카드 신청입니다. 입과 전에 상담과 간단한 실기로 기초를 확인합니다. 훈련비와 자부담은 고용24에서 과정명으로 확인하십시오.

학원을 비교할 때 볼 항목은 「게임학원 고르는 법」 글에 있습니다.

강의는 세 개 봤는데 빈 프로젝트에서 멈춘 20대 구직자 (가상 사례)

아래는 상담에서 자주 나오는 고민을 재구성한 가상 사례입니다.

상황 — 게임과 무관한 전공으로 졸업한 20대 구직자입니다. 유튜브 유니티 강의 세 개를 끝까지 따라 했고 노트북 메모리는 8GB입니다.

고민 — "따라 할 때는 되는데 새 프로젝트를 열면 뭘 해야 할지 모르겠습니다. 노트북도 바꿔야 하나요?"

확인한 것 — 강의마다 유니티 버전이 달라 화면이 매번 달랐습니다. 변수와 조건문은 알았지만 함수와 클래스를 직접 만들어 본 적은 없었습니다. 끝까지 만든 게임도 없었습니다.

세운 계획 — 버전을 Unity 6.3 LTS 하나로 정하고 Unity Essentials를 2주 동안 끝내기로 했습니다. 그다음 한 달은 강의 없이 공 피하기 게임 한 개를 완성하기로 했습니다. 노트북은 그대로 쓰고 국비는 상담에서 과정을 확인한 뒤 정하기로 했습니다.
