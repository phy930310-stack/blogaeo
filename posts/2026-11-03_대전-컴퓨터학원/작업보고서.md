## 1. 질문 지도
- 대표 키워드: 대전 컴퓨터학원 — 새 묶음 "대전 컴퓨터학원 고르기 (목적별 종류·확인 방법·국비)". 포함 키워드 대전컴퓨터학원(560)·대전코딩학원(120)·둔산동컴퓨터학원(50)·대전국비지원컴퓨터학원(25)·대전둔산동컴퓨터학원(25)·대전은행동컴퓨터학원(15)·대전중구컴퓨터학원(15)·대전국비컴퓨터학원(10), 합산 약 820. 유형 지역·전환.
- 핵심 질문: 대전에서 컴퓨터학원을 고를 때 목적별로 어떤 학원을 봐야 하고, 등록·국비 여부는 어떻게 확인하나?
- 하위 질문
  1. 목적에 따라 어떻게 나뉘나? (자격증·사무 / 코딩 입문 / 제작 기술 — 표 1 + 인포그래픽)
  2. 등록된 학원인지 어떻게 확인하나? (학원법 등록·등록번호, 나이스 학원서비스, 공공데이터포털, 교육지원청 문의)
  3. 국비로 다닐 수 있는 학원은 어떻게 찾나? (고용24 과정 검색, 한도·자부담·유효기간, 140시간 이상 훈련 상담, 상담 → 과정 확인 → 카드 신청)
  4. 고등학생과 성인은 각각 무엇을 기준으로 고르나? (포트폴리오·면접 전형 결과물 / 취업 결과물·시간대·국비)
  5. SBS아카데미게임학원 대전점은 어떤 경우에 맞나? (제작 기술 과정 목록·국비 3과정·입과 전 확인 / 사무 자격증은 맞지 않음)
- 후속 질문: 게임학원 고르는 법(10-15, 상담 체크리스트·환불) / 대전 국비지원 교육(10-19, 카드 신청 단계) / 대전 미술학원(10-29, /22 링크).
- 기존 글과의 분담: 10-15 글은 게임학원 상담 질문표·환불 기준, 10-19 글은 내일배움카드 신청 단계·국가기간직종, 10-29 글은 실기 vs 포트폴리오 전형. 이 글은 '컴퓨터학원'이라는 넓은 검색어를 목적별로 갈라 주고 **교육청 등록 확인 방법**을 새로 다뤘다. 상담 질문표·환불·카드 단계는 반복하지 않고 제목만 언급해 연결했다.
- 포지셔닝: 고등학생 안내는 포트폴리오·면접 전형, 국비 순서는 "상담 → 과정 확인 → 카드 신청". 학원 정보는 brand/profile.md의 과정 목록·국비 3과정·입과 전 확인(상담+간단한 실기)·NAP만 사용. 강사진·수강료·취업률·합격률·연봉·다른 학원 실명·비교 없음. 사무 자격증 목적이면 이 학원이 맞지 않는다고 명시.

## 7. 발행 전 확인
- 학원법의 등록·등록증명서·미등록 제재 조문과 나이스 학원서비스의 조회 화면(교습비 조회 가능 여부)은 검색 요약 기준 → 국가법령정보센터·neis.go.kr 원문 대조 권장. 본문 Q2 첫 두 문단과 FAQ 2문항이 해당.
- FAQ "학원 광고물과 홈페이지에 등록번호가 표시돼 있다"는 학원법 광고 표시 의무를 근거로 한 서술 → 시행령 조문 대조 권장.

- 과정 목록(웹소설·게임기획·AI개발·애니메이션 포함)이 현재 운영 과정과 일치하는지, "입시·취업 포트폴리오 모두 다룬다"는 표현이 맞는지 사용자 확인.
- 학원 광고 표시 문구(등록번호·교습비)는 사용자가 직접 삽입.
