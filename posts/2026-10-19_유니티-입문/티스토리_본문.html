Q2. 유니티는 어떤 순서로 시작하면 되나요?

설치부터 첫 게임 완성까지 다섯 단계로 나누면 중간에 막히는 일이 줄어듭니다.

  1. Unity Hub 설치 — Hub에서 에디터 버전을 고르고 2D 또는 3D 템플릿으로 새 프로젝트를 만듭니다.
  2. 에디터 화면 익히기 — Scene(작업 화면), Game(실행 화면), Hierarchy(오브젝트 목록), Inspector(속성), Project(파일) 다섯 창의 역할을 알아 둡니다.
  3. 오브젝트와 컴포넌트 — 모든 것은 오브젝트이고, 움직임·충돌·소리 같은 기능은 컴포넌트를 붙여서 만든다는 구조를 이해합니다.
  4. C# 스크립트로 움직이기 — 키 입력으로 캐릭터를 움직이고, 부딪히면 점수가 오르는 간단한 규칙을 코드로 씁니다.
  5. 작은 게임 완성 — 시작 화면부터 게임 오버까지 있는 미니 게임 하나를 만들고 실행 파일로 빌드해 봅니다.

Q3. C#은 어느 정도 알아야 유니티를 할 수 있나요?

첫 게임을 만드는 데 필요한 C#은 생각보다 적습니다. 아래 내용을 알면 시작할 수 있고, 나머지는 게임을 만들면서 필요할 때 익히면 됩니다.

알아야 할 것 유니티에서 쓰이는 곳 예시
변수 점수·체력·속도 저장 int score = 0;
조건문·반복문 충돌 판정, 적 여러 마리 처리 if (hp <= 0) GameOver();
함수·클래스 기능 묶기, 스크립트 구조 Start(), Update()

특히 유니티 스크립트의 기본인 Start()는 시작할 때 한 번, Update()는 매 프레임마다 실행된다는 점만 이해해도 대부분의 입문 예제를 따라갈 수 있습니다.
