==================================================
네이버 붙여넣기 안내 (메모장으로 여세요)
==================================================

순서: ① 제목 → ② 본문 → ③ 서식 → ④ 사진 → ⑤ 지도 → ⑥ 태그 → ⑦ 발행 전 확인


① 제목 — 제목 칸에 붙여넣기
--------------------------------------------------
게임회사 취업, 신입은 뭘 준비해야 할까요? 직군별 포트폴리오까지 대전 게임학원이 정리했어요


② 본문
--------------------------------------------------
네이버_본문.txt 를 메모장으로 열어 전체 복사(Ctrl+A → Ctrl+C) → 본문에 붙여넣기


③ 서식 적용 (가독성에 가장 큰 영향)
--------------------------------------------------
- 본문 전체 선택 → 글자 크기 15
- [소제목] 으로 시작하는 줄 → 툴바 '소제목' 서식 → "[소제목] " 글자 삭제
  (소제목 서식이 없으면: 굵게 + 글자 크기 19)
- [인용구] 로 시작하는 요약 부분 → 툴바 '인용구' → '라인' 스타일 → 왼쪽 정렬 → "[인용구] " 글자 삭제


④ 사진 — 안내 줄 자리에 올리고, 사진 아래 '사진 설명' 칸에 입력 → 안내 줄 삭제
--------------------------------------------------
[생성 이미지]
   1) 네이버_썸네일.png
      → 사진 설명: 게임회사 신입 취업, 직군부터 정하고 포트폴리오로 증명해요
   2) 공통_hiring-flow.png
      → 사진 설명: 게임회사 신입 채용은 보통 서류, 직무 테스트, 면접 3단계로 진행돼요
   3) 공통_job-map.png
      → 사진 설명: 게임회사 다섯 직군과 직군별 신입 준비물
   4) 공통_portfolio-by-role.png
      → 사진 설명: 직군별로 포트폴리오에 꼭 들어가야 할 것

[실제 사진 — 직접 촬영]
   실제 사진 1: 수강생 포트폴리오 작업 화면이나 출력물을 찍은 사진. 학생 동의를 받은 작품만, 이름·얼굴이 보이지 않게
      → 사진 설명: 직군에 맞춰 포트폴리오를 만들어 가는 작업 과정
   실제 사진 2: 학원 강의실에서 수업·실습 중인 모습을 뒤쪽에서 넓게 찍은 사진. 모니터 화면 위주, 얼굴이 나오지 않게
      → 사진 설명: SBS아카데미게임학원 대전점 실습 강의실

   촬영 공통: 가로 4:3 / 밝게 / 얼굴·이름·모니터 속 개인정보가 보이지 않게 / 글자 합성·스톡 사진 금지
             네이버와 티스토리에는 같은 사진 말고 다른 컷 사용


⑤ 지도
--------------------------------------------------
맨 아래 [지도] 줄 자리 → 툴바 '장소' → "SBS아카데미게임학원 대전점" 검색 → 추가 → [지도] 줄 삭제


⑥ 태그 — 태그 칸에 붙여넣기 (한 덩어리로 들어가면 하나씩 입력)
--------------------------------------------------
#게임회사취업 #게임회사 #게임업계취업 #게임회사채용 #게임포트폴리오 #게임업계 #게임QA #게임취업 #대전게임학원 #SBS아카데미게임학원대전점


⑦ 발행 전 확인 — 아래는 '지우면 안 되는 본문'입니다
--------------------------------------------------
[ ] 소제목 "… (가상 사례)" 와 바로 아래 고지 문장이 남아 있다
[ ] "참고 자료" 목록이 연락처 위에 남아 있다
[ ] 연락처 아래에 지도가 들어갔다
[ ] 본문에 "[" 로 시작하는 안내 표시가 남아 있지 않다 (Ctrl+F 로 "[" 검색)
