==================================================
네이버 붙여넣기 안내 (메모장으로 여세요)
==================================================

순서: ① 제목 → ② 본문 → ③ 서식 → ④ 사진 → ⑤ 지도 → ⑥ 태그 → ⑦ 발행 전 확인


① 제목 — 제목 칸에 붙여넣기
--------------------------------------------------
게임기획자 되려면 뭐부터 해야 할까요? 기획 직무 종류부터 포트폴리오까지 정리했어요


② 본문
--------------------------------------------------
네이버_본문.txt 를 메모장으로 열어 전체 복사(Ctrl+A → Ctrl+C) → 본문에 붙여넣기


③ 서식 적용 (가독성에 가장 큰 영향)
--------------------------------------------------
- 본문 전체 선택 → 글자 크기 15
- [소제목] 으로 시작하는 줄 → 툴바 '소제목' 서식 → "[소제목] " 글자 삭제
  (소제목 서식이 없으면: 굵게 + 글자 크기 19)
- [인용구] 로 시작하는 요약 부분 → 툴바 '인용구' → '라인' 스타일 → 왼쪽 정렬 → "[인용구] " 글자 삭제


④ 사진 — 안내 줄 자리에 올리고, 사진 아래 '사진 설명' 칸에 입력 → 안내 줄 삭제
--------------------------------------------------
[생성 이미지]
   1) 네이버_썸네일.png
      → 사진 설명: 게임기획자, 아이디어보다 문서가 먼저예요
   2) 공통_planner-roles.png
      → 사진 설명: 게임기획 네 분야와 각자 만드는 문서
   3) 공통_planner-roadmap.png
      → 사진 설명: 게임기획자 공부 순서 다섯 단계
   4) 공통_planner-portfolio.png
      → 사진 설명: 기획 포트폴리오에 들어갈 4가지

[실제 사진 — 직접 촬영]
   실제 사진 1: 수강생이 기획서나 엑셀 밸런스 시트를 작성 중인 모니터 화면. 얼굴·이름은 안 보이게
      → 사진 설명: 기획서와 밸런스 시트를 직접 써 보는 수업
   실제 사진 2: 팀 프로젝트 회의나 강의실 모습을 뒤쪽에서 넓게 찍은 사진. 얼굴이 나오지 않게
      → 사진 설명: SBS아카데미게임학원 대전점 강의실

   촬영 공통: 가로 4:3 / 밝게 / 얼굴·이름·모니터 속 개인정보가 보이지 않게 / 글자 합성·스톡 사진 금지
             네이버와 티스토리에는 같은 사진 말고 다른 컷 사용


⑤ 홈페이지 링크 카드 · 지도
--------------------------------------------------
"▶ 게임학원 홈페이지: http://…" 줄의 주소 부분만 복사 → 바로 아래 빈 줄에 붙여넣고 Enter → 링크 카드(미리보기)가 생기면 성공
(카드가 생기지 않아도 글자 링크로 동작합니다)
맨 아래 [지도] 줄 자리 → 툴바 '장소' → "SBS아카데미게임학원 대전점" 검색 → 추가 → [지도] 줄 삭제


⑥ 태그 — 태그 칸에 붙여넣기 (한 덩어리로 들어가면 하나씩 입력)
--------------------------------------------------
#게임기획자 #게임기획 #게임기획자되는법 #게임기획서 #역기획서 #게임기획포트폴리오 #시스템기획 #게임기획전문가 #대전게임학원 #SBS아카데미게임학원대전점


⑦ 발행 전 확인 — 아래는 '지우면 안 되는 본문'입니다
--------------------------------------------------
[ ] 소제목 "… (가상 사례)" 와 바로 아래 고지 문장이 남아 있다
[ ] "참고 자료" 목록이 연락처 위에 남아 있다
[ ] 연락처 아래에 지도가 들어갔다
[ ] 본문에 "[" 로 시작하는 안내 표시가 남아 있지 않다 (Ctrl+F 로 "[" 검색)
