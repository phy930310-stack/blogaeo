## 3. 다음 목표: 네이버 업로드 완전 자동화 (Claude in Chrome)
> 사용자 요청 "크롬in클라우드"는 **Claude in Chrome**(Claude가 사용자의 크롬을 직접 조작하는 기능)으로 이해했습니다. 다르면 정정해 주세요.

### 3-1. 원칙 (티스토리와 동일하게 유지)
- 로그인은 사람이 직접. 비밀번호·쿠키를 저장소에 저장하거나 출력하지 않음
- 자동화는 **비공개 발행 또는 임시저장까지**. 공개 발행은 사람이 검수 후 직접 (CLAUDE.md: 발행·삭제 등은 사용자 확인 후에만)
- 저장 전 화면에서 '비공개' 선택을 확인하지 못하면 저장하지 않고 멈춤

### 3-2. 자동화할 단계 (`posts/<폴더>/` 기준)
1. 네이버 블로그 글쓰기 화면 열기 — **네이버 블로그 아이디 필요(아직 저장소에 없음 → 사용자에게 받아 `brand/profile.md`에 기록)**
2. 제목: `meta.json`의 `naver_title`
3. 본문: `네이버_붙여넣기용.html`의 [본문 복사] → 본문에 붙여넣기
4. 노란 안내 줄(🖼 이미지 넣는 자리) 위치마다 `images/<파일>.png` 업로드 → 사진 설명 입력 → 안내 줄 삭제 (4장)
5. 📍 지도 줄: 툴바 '장소' → `meta.json`의 `map_name` 검색 → 추가 → 안내 줄 삭제
6. (선택) 남색 굵은 줄 → '소제목' 서식, 💡 묶음 → '인용구' 서식
7. 태그: `naver_tags` 10개 / 카테고리 지정
8. 공개 설정 **비공개** 확인 → 발행(또는 임시저장)

### 3-3. 예상 난관 (로컬에서 먼저 확인할 것)
- **이미지 업로드**: 사진 버튼이 OS 파일 선택 창을 띄움. Claude in Chrome으로 로컬 파일을 넣을 수 있는지 확인 필요(추측: 어려울 수 있음). 안 되면 Playwright의 `setInputFiles` 방식(티스토리 업로더와 동일)이 확실함
- **SmartEditor ONE 구조**: 편집 영역이 일반 입력칸이 아니라 버튼 위치·구조가 바뀔 수 있음 → 버튼을 글자(라벨)로 찾고, 못 찾으면 멈추게
- **네이버 운영정책**: 자동 프로그램 사용 관련 조항을 확인하지 못함 → 사람 속도로 1일 1편, 비공개 저장까지만 권장(확인 필요)

### 3-4. 권장 진행 순서
1. Claude in Chrome으로 글 1편을 **대화형으로** 비공개 업로드해 보며 단계별 버튼·막히는 지점 기록
2. 매일 반복 가능하게 하려면 그 기록을 바탕으로 `tools/tistory-uploader`에 네이버 모드를 추가(같은 크롬 로그인 프로필 방식, `upload.cmd`에서 플랫폼 선택)하는 것을 검토 — 화면 조작이 매번 같아 더 안정적일 것으로 예상(추측)
3. 첫 시험 글: `posts/2026-10-27_웹소설-쓰는-법` (아직 네이버 미발행이라면)
