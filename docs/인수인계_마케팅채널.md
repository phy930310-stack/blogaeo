## 4. 규칙·주의
- `CLAUDE.md`: 한국어 합쇼체, 추측은 추측이라고 명시, 지어낸 학원 정보 금지, 매 작업 후 커밋·push·zip 전달.
- 저장소는 **공개**다. 토큰·웹후크 주소·학생 정보·내부 자료를 커밋하지 않는다. 로고는 공개된 자료라 넣어 두었다.
- `.gitignore`에 `images/`가 있어 그 이름의 폴더는 커밋되지 않는다(폼 이미지가 이 때문에 한 번 빠졌었다). 이미지 폴더는 `assets/`를 쓴다.
- 이미지 렌더링: `.canvas` 요소를 `node .claude/skills/aeo-blog/scripts/render.mjs <폴더>`로 PNG 저장. 폰트는 `.claude/skills/aeo-blog/assets/fonts/`.
- 인스타 새 계정은 짧은 시간에 여러 개 올리면 제한될 수 있다(추정) → 하루 1개.
- Meta·인스타·구글 화면 명칭은 자주 바뀐다. 안내와 다르면 사용자에게 화면 캡처를 요청한다.
- 디스코드 알림은 연락처를 일부 가린 요약만 보낸다(개인정보). 전체는 응답 시트.
