# "키워드 → 발행용 원고" AEO 블로그 자동화 개요

## 최종 목표

```
사용자: "/aeo-blog 게임학과 내신 5등급"
   ↓ (자동)
posts/2026-10-01_게임학과-내신-5등급/
   ├─ post.md            ← 발행용 본문 (질문형 제목 + 답변 블록)
   ├─ faq-schema.html    ← 티스토리 HTML 모드용 FAQPage JSON-LD
   ├─ instagram.md       ← 같은 질문의 인스타 카드뉴스 문구(선택)
   └─ report.md          ← 질문 설계 근거, 출처 목록, 체크리스트 결과, 사람이 확인할 항목
```

## 파이프라인 7단계

| 단계 | 이름 | 하는 일 | 산출물 |
|---|---|---|---|
| 0 | 입력 정리 | 키워드 + (선택) 메모·상담 사례·플랫폼 받기. 브랜드 프로필(`brand/profile.md`) 로드 | 작업 폴더 |
| 1 | 질문 변환 | 키워드를 **상황형 질문**으로 변환. 핵심 질문 1개 + 하위 질문 4~6개 + 후속 질문 2~3개(질문군) | 질문 지도 |
| 2 | 리서치 | 웹 검색으로 공식 자료(모집요강·기관 통계 등) 수집, **기준 시점·URL 기록**. 확인 불가 정보는 `[확인 필요]` 표시 | 근거 목록 |
| 3 | 개요 작성 | 아래 「원고 표준 구조」에 질문·근거 배치 | 개요 |
| 4 | 본문 작성 | 각 소제목마다 답변 블록 4단계 적용, 브랜드 맥락 자연 삽입 | post.md |
| 5 | 기계 가독성 | FAQPage JSON-LD 생성(본문 문장과 토씨까지 동일), 메타 설명·태그 | faq-schema.html |
| 6 | 자체 검수 | AEO 체크리스트 12항목 자동 점검 → 미달 항목 수정 후 재검 | report.md |
| 7 | 채널 파생(선택) | 인스타 카드뉴스 문구(질문 1개 → 첫 장 질문 / 캡션 첫 문장 답) | instagram.md |

## 원고 표준 구조

```
[제목]    질문형 핵심 질문 | 브랜드·지역 보조어
          예) 게임학과는 내신 5등급이면 진학하기 어려울까? | 대전 게임학원 입시 가이드

[서두 즉답 3~5줄]
          결론 1문장 → 이유 1문장 → 이 글에서 다루는 범위 1문장
          (+ 기준 시점: "2027학년도 모집요강 기준")

[요약 박스] 핵심 답 3줄 요약 (AI가 통째로 인용하기 좋은 단위)

[H2 Q1. 하위 질문]   ← 답변 블록 4단계
[H2 Q2. 하위 질문]
[H2 Q3. 하위 질문]   (정의 블록 / 단계 블록 / 비교표 중 질문 성격에 맞는 형식)
[H2 Q4. 하위 질문]

[H2 실제 상담에서 자주 나오는 사례]   ← E-E-A-T 경험 근거 (사용자 제공 사례만 사용)

[H2 자주 묻는 질문(FAQ)]   ← 3~5개, 각 2~3문장. 스키마와 동일 문장

[H2 다음으로 궁금한 질문]  ← 후속 질문 2~3개 (다음 글 예고/내부 링크)

[작성자·기관 정보]  누가, 어떤 경력으로, 언제 기준으로 작성했는지
[참고 자료]        출처 URL + 확인 일자
```

## 품질 기준(정량)

| 항목 | 기준 |
|---|---|
| 분량 | 본문 2,000~3,500자 (네이버 기준 기존 관행 범위, 고정값 아님) |
| 즉답 위치 | 서두 첫 3문장 내 결론 / 각 H2 첫 1~3문장 내 결론 |
| 섹션 답변 길이 | 첫 답변 80~150자 내 완결 |
| 근거 밀도 | H2마다 근거(수치·공식 자료·사례) 최소 1개 + 기준 시점 |
| 금지 | 출처 없는 성과 단정, 창작 후기·사례, 키워드 반복 나열, 한 글에 질문 여러 개 |

## 사람이 반드시 확인할 항목 (자동화 한계)

- `[확인 필요]` 표시된 수치·전형 정보 (모집요강은 매년 바뀜)
- 상담 사례의 실제 여부 (자동으로 사례를 창작하지 않음 → 사례 입력이 없으면 해당 섹션은 템플릿만 남김)
- 브랜드 정보(학원명·주소·전화·운영시간)가 네이버 플레이스/홈페이지와 일치하는지

## 확정 사항 (2026-10-01)

1. **플랫폼**: 네이버 + 티스토리, 하루 1키워드 → 2편. 같은 사실을 쓰되 제목·서두·섹션 순서·문장을 다르게 작성(유사문서 방지).
2. **브랜드 프로필**: `brand/profile.md` 입력 완료 (운영 과정명·강사 경력은 추후 입력).
3. **사례**: 가상 사례 사용. 단, "재구성한 가상 사례" 고지 필수, 실명·합격/취업 결과 미기재.
4. **자동화 범위**: 원고 + 이미지(썸네일 2장, 인포그래픽)까지. 붙여넣기·발행은 사용자가 직접.
5. **스킬 운영**: `aeo-blog`를 기존 `naver-blog-post` 스킬과 독립적으로 운영.
