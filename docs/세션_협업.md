# 세션 간 협업 방식 (2026-10-24 점검)

## 이 클라우드 세션에서 보이는 세션
| 종류 | 예 | 메시지 보내기 |
|---|---|---|
| 클라우드 세션 | 다른 플랫폼 광고 전략, 블로그 작성, 수강 로드맵 UI, 학생관리 웹앱(GIT) | 가능 |
| PC의 Remote Control 세션 (`claude remote-control`) | Kegone 인트라넷 구조 파악(회사 PC), 입시(회사B)·입시(집A)·학생관리 웹앱(로컬) | 가능 — 2026-10-24 사용자 승인 1회 완료 |
| 보이지 않음 | "상담 준비 자료정리", "게임대전 주차별 일정 정리" | 불가 — Claude 데스크톱 앱의 로컬/Cowork 세션으로 추정(세션 목록 API에 나오지 않음) |

- PC 세션에 메시지를 보내려면 사용자 승인이 한 번 필요하다. 승인하면 이 세션은 신뢰 기기에서만 쓸 수 있게 고정되고, 되돌릴 수 없다.
- 메시지는 **텍스트만, 최대 64KB**까지 보낼 수 있다. 받는 세션은 이 메시지를 지시가 아니라 동료가 보낸 참고 정보로 받아들이고, 할지 말지는 스스로 판단한다.
- 세션끼리 파일을 직접 주고받는 기능은 없다.

## 파일 전달 경로
1. **구글 드라이브**: 클라우드 세션이 드라이브 커넥터로 읽고 내려받을 수 있다. 로고처럼 큰 파일에 권장한다.
2. **GitHub 저장소**: `blogaeo`는 **공개 저장소**다. 공개해도 되는 파일만 올린다. 내부 자료, 학생 정보, 수강료는 올리지 않는다.
3. **대화창 첨부**: 사용자가 직접 올린다.

## 안 보이는 세션을 연결하려면 (공식 문서 기준, 2026-10-24 확인)
- **이미 열려 있는 세션**(데스크톱 앱 Code 탭이나 터미널): 입력창에 `/remote-control`을 입력한다. 짧게 `/rc`도 된다. 대화 내용이 그대로 이어진다.
  - 처음 한 번은 'Enable Remote Control' 확인 창이 뜬다.
  - 같은 명령을 다시 입력하면 연결이 끊긴다.
- **데스크톱 앱 설정**: Settings > Claude Code > `Connect new sessions to Remote Control`을 켜면 새로 여는 세션이 자동으로 연결된다. 세션 하나만 연결하려면 세션 상세 패널의 Environment 카드에 있는 **Remote Control** 스위치를 켠다.
- **Cowork 세션**: Remote Control을 지원하는지 공식 문서로 확인하지 못했다.
- PC가 켜져 있고 앱(또는 터미널)이 열려 있어야 연결이 유지된다.
- 새 세션으로 시작해도 된다면 `tools/remote-control/리모트시작.cmd`처럼 작업 폴더에서 `claude remote-control`을 실행한다.
