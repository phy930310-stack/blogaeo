# "그려줘" 이미지 생성 환경 구축 — 진행 상황 (2026-10-18 중단)

## 목표
Claude Code에서 "그려줘" → Claude가 영어 프롬프트 작성 → Codex CLI(ChatGPT 구독) 또는 Antigravity CLI(구글 계정)로 이미지 생성 → `./images/날짜_도구명.png` 저장.
API 키 금지, 구독 계정 OAuth 로그인만. 설치·로그인 등 시스템 변경은 실행 전 사용자 확인.

## 사용자 결정
- 구축 위치: **둘 다** (클라우드 세션에서 먼저 시험 → 되면 PC(Windows)용 안내서·스킬 제작)
- 서비스: **둘 다** (ChatGPT/Codex + 구글/Antigravity), 비교 모드 포함

## 1단계 환경 점검 (클라우드 컨테이너)
| 항목 | 결과 |
|---|---|
| OS | Ubuntu 24.04 (클라우드 컨테이너 — 사용자 PC 아님, 세션 종료 시 설치·로그인 사라짐) |
| Node / npm | v22.22.0 / 10.9.4 |

## 2단계 설치 (클라우드, 사용자 승인 후 완료)
- Codex CLI: `npm install -g @openai/codex` → **codex-cli 0.163.0** (`/opt/node22/bin/codex`)
- Antigravity CLI: 공식 스크립트 `https://antigravity.google/cli/install.sh` (내용 확인: `~/.local/bin/agy` 설치, sudo 없음, SHA-512 검증) → **agy 1.4.2**, 명령 이름 `agy`
- ⚠ 컨테이너가 재시작되면 재설치 필요

## --help로 확인한 사실
| 항목 | Codex | agy |
|---|---|---|
| 로그인 | `codex login --device-auth` (주소+일회용 코드, 15분 유효) / `codex login status` | 별도 login 명령 없음. "인자 없이 실행하면 로그인"(`agy models` 오류 문구) |
| 헤드리스 | `codex exec` (`--skip-git-repo-check`, `-C <dir>`, `-s <sandbox>`) | `agy -p` / `--print`, `--output-format json`, `--print-timeout` |
| 이미지 생성 | `codex features list` → `image_generation  stable  true` | 도움말에 언급 없음 → 로그인 후 `agy models`로 확인 필요 |

## 중단 지점
- Codex device 로그인 코드를 띄웠으나 사용자가 시간이 늦어 중단 → 로그인 대기 프로세스 종료함(코드 만료, 로그인 안 됨)

## 다음에 할 일

3. `agy` 첫 실행 로그인 방식 확인(클라우드에서 브라우저 로그인 가능 여부) → 안 되면 PC에서만 진행
4. 3단계: 테스트 프롬프트 "게임 아카데미 홍보용, 밝은 분위기의 2D 게임 캐릭터 일러스트, 정사각형" → `./images/YYYY-MM-DD_codex.png`, `_agy.png` 비교
5. 4단계: "그려줘" 스킬 초안(도구 지정·비교 모드·비율) → 사용자 확인 후 저장

7. 5단계 완료 보고(5줄 이내)
