# 티스토리 비공개 업로더 (Windows)

aeo-blog가 만든 원고 폴더를 티스토리에 **비공개 저장**까지 자동으로 넣어 주는 프로그램입니다.
제목·본문·이미지(대체텍스트 포함)·FAQ 코드·카테고리·태그를 입력하고, 공개 전환은 사람이 직접 합니다.

## 안전 원칙
- 로그인은 사람이 직접 합니다. 비밀번호는 저장하지 않습니다(로그인 세션은 이 PC의 `%LOCALAPPDATA%\blogaeo-uploader\profile`에만 저장).
- 항상 **비공개 저장**만 합니다. '비공개' 선택과 '비공개 저장' 버튼을 확인하지 못하면 저장하지 않고 멈춥니다.
- `%LOCALAPPDATA%\blogaeo-uploader` 폴더는 로그인 세션이 들어 있으므로 다른 사람에게 주지 마세요.

## 처음 한 번
1. 이 폴더를 원하는 곳에 압축 해제 (예: `D:\정리파일\박현용\블로그\tistory-uploader`)
2. `setup.cmd` 더블클릭 — Node.js가 없으면 설치(관리자 승인 창이 뜰 수 있음) → 설치 후 `setup.cmd` 한 번 더
3. `config.json`을 메모장으로 열어 `blogUrl`이 내 티스토리 주소인지 확인
4. `login.cmd` 더블클릭 → 열린 크롬 창에서 카카오 로그인 → "로그인 완료"가 뜨면 끝
5. 티스토리 카테고리 확인 (원고는 "입시 정보", "취업 정보" 카테고리로 저장됨 — 이미 만들어져 있음)

## 매번 (글 1편)
1. Claude에게 받은 원고 압축 파일을 `posts` 폴더 안에 풀기
   → `posts\2026-10-03_게임학과-종류\tistory.html` 형태가 되면 정상
2. (선택) 직접 찍은 사진을 그 글 폴더의 `photos` 폴더에 `실제사진1.jpg` 이름으로 넣기
   → 없으면 그 자리에 안내 줄이 남으니, 티스토리 편집 화면에서 직접 넣으면 됩니다
3. (선택) `preview.cmd` → 글 폴더의 `preview.html`을 열어 미리 확인
4. `upload.cmd` 더블클릭 → 번호 선택 → 크롬 창에서 자동 입력이 진행됨 (마우스·키보드를 건드리지 마세요)
5. "[완료] 비공개 저장됨"이 뜨면 티스토리 '글 관리'에서 검수 → **공개로 전환**
6. 공개 후 Claude에게 글 주소를 주면 화면·검색 수집 준비(robots·RSS·사이트맵)까지 점검

## 문제가 생기면
- "로그인이 필요합니다" → `login.cmd` 다시 실행
- "버튼을 찾지 못했습니다" → 티스토리 화면이 바뀐 경우입니다. 창 캡처와 메시지를 Claude에게 전달
- "FAQ 코드가 제거되었습니다" → 저장하지 않고 멈춘 것입니다(정상 방어). 메시지를 전달해 주세요
- 실패해도 원고·이미지는 그대로이니, 해결 후 `upload.cmd`를 다시 실행하면 됩니다
