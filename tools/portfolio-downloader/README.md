# 학생 포트폴리오 다운로드 도구

학원 홈페이지(`sbsdaejeon-game.co.kr`) 학생 포트폴리오 이미지를 한꺼번에 내려받습니다. 사용자 PC에서 실행합니다(클라우드에서는 학원 사이트 접속 불가).

1. 이 폴더(아무 위치나 가능)에서 `작품다운로드.cmd` 더블클릭
   - 처음 한 번은 부품(playwright)을 자동 설치합니다. 브라우저는 PC의 Chrome/Edge를 씁니다.
2. 결과: `학생작품\보기.html`(한눈에 보기), `학생작품\001_제목\01.jpg …`, `학생작품\목록.csv`
3. 다시 실행해도 이미 받은 이미지는 건너뜁니다.

다른 목록(카테고리)을 받으려면: `작품다운로드.cmd "목록주소" 최대페이지수`

작품을 못 찾으면 `학생작품\_구조확인.html`을 Claude에게 보내 주세요.
