# 상담 신청 구글 폼 만들기 (약 3분, 한 번만)

`create_form.gs`를 한 번 실행하면 대표님 구글 드라이브에 다음 세 가지가 만들어집니다.
- 상담 신청 폼: 입시와 취업으로 질문이 나뉘는 분기형
- 응답이 쌓이는 구글 시트
- 새 신청 알림: 디스코드(아래 '디스코드 알림 연결')와 phy930310@gmail.com 메일(예비)

## 실행 순서 (PC 권장)
1. https://script.google.com 에 접속해 **새 프로젝트**를 누릅니다.
2. 왼쪽 위 '제목 없는 프로젝트'를 눌러 이름을 `상담폼 생성`으로 바꿉니다.
3. 편집기에 있는 기존 코드(`function myFunction() {...}`)를 모두 지우고, `create_form.gs`의 내용을 전부 붙여 넣은 뒤 저장(Ctrl+S)합니다.
4. 위쪽 함수 선택 칸에서 `createConsultForm`을 고르고 **실행**을 누릅니다.
5. 권한 요청 창이 뜨면 **권한 검토** → 본인 계정 선택 → '확인되지 않은 앱' 화면에서 **고급** → **상담폼 생성(으)로 이동** → **허용** 순서로 진행합니다.
   - 대표님이 직접 만든 스크립트라서 나오는 정상적인 경고입니다.
6. 실행이 끝나면 아래 **실행 로그**에 주소 3개가 나옵니다.
   - **응답용 주소**: 블로그와 인스타에 넣을 주소이므로 Claude에게 전달해 주십시오.
   - **편집 주소**: 관리자용이므로 외부에 공유하지 마십시오.
   - **응답 시트** 주소

## 디스코드 알림 연결 (약 5분, PC 권장)
알림에는 연락처 일부를 가린 요약과 응답 시트 링크만 담깁니다. 이름이나 전체 번호 같은 전체 정보는 시트에서 확인하십시오.
메일 알림은 디스코드가 끊겼을 때를 대비한 예비용으로 함께 옵니다. 필요 없으면 코드 위쪽의 `SEND_EMAIL`을 `false`로 바꾸면 됩니다.

1. **디스코드 서버 만들기**: 디스코드 왼쪽 **＋** 버튼 → '직접 만들기' → '나와 친구들을 위한 서버' → 이름은 `학원 상담 알림`으로 정합니다.
2. **웹후크 만들기**: 채널(`#일반`) 옆 톱니바퀴 → **연동** → **웹후크** → **새 웹후크** → **웹후크 URL 복사**
   - 이 주소는 비밀번호와 같습니다. 채팅창이나 Claude 대화창에 붙여 넣지 마십시오.
3. **스크립트에 주소 넣기**: script.google.com의 같은 프로젝트에서 왼쪽 톱니바퀴(**프로젝트 설정**) → 맨 아래 **스크립트 속성** → **스크립트 속성 추가**
   - 속성: `DISCORD_WEBHOOK_URL`
   - 값: 2번에서 복사한 주소
   - **스크립트 속성 저장**을 누릅니다.
4. **연결 테스트**: 편집기 위쪽 함수 선택 칸에서 `testDiscord`를 고르고 **실행**합니다.
   - 권한 창이 다시 뜨면 허용합니다. '외부 서비스 연결' 권한이 새로 필요해서 나오는 창입니다.
   - 디스코드에 "연결 테스트입니다" 메시지가 오면 설정이 끝난 것입니다.
   - **이 테스트를 한 번 실행해야 실제 신청 알림도 작동합니다.**
5. 휴대폰에 디스코드 앱을 설치하고, 해당 서버의 알림을 '모든 메시지'로 설정합니다.

> 폼을 이미 만든 상태에서 코드만 새 버전으로 바꾸는 경우: **같은 프로젝트**에서 코드를 통째로 바꿔 붙여 넣고 저장한 뒤 3~4번만 하시면 됩니다. `createConsultForm`은 다시 실행하지 마십시오. 새 프로젝트에 붙여 넣으면 기존 폼과 연결되지 않습니다.

### 429 오류가 날 때 (`error code: 1015`)
대표님 설정이 잘못된 것이 아닙니다. 디스코드 앞단의 Cloudflare가 **구글 서버에서 오는 요청을 '너무 많다'고 보고 막는** 현상입니다. 구글 앱스 스크립트는 전 세계 사용자가 같은 서버를 나눠 쓰기 때문에 이런 일이 생깁니다.
그래서 디스코드 전송이 실패해도 **메일 알림은 먼저 나가도록** 되어 있습니다.

**1단계: 다시 시도하기**
- 30분에서 1시간쯤 지난 뒤 `testDiscord`를 다시 실행해 봅니다.
- 코드가 실패 시 자동으로 두 번 더 시도합니다.
- 차단은 일시적인 경우가 많지만, 계속 반복될 수도 있습니다.

**2단계: 그래도 안 되면 중계 서버 쓰기 (무료, 약 10분)**
구글과 디스코드 사이에 무료 중계 서버(Cloudflare Workers)를 하나 둡니다. 디스코드에 요청을 보내는 쪽이 구글 서버가 아니게 되므로 차단을 피할 수 있습니다.
1. https://dash.cloudflare.com 에 가입하고 로그인합니다. 무료 요금제로 충분합니다.
2. **Workers & Pages** → **Create** → **Create Worker** → 이름은 `discord-relay`로 정하고 → **Deploy**
3. **Edit code**를 누르고, 기존 코드를 모두 지운 뒤 `tools/discord-relay/worker.js` 내용을 붙여 넣고 **Deploy**합니다.
4. 화면에 나온 워커 주소(예: `https://discord-relay.아이디.workers.dev`)를 복사합니다.
5. 스크립트 속성 `DISCORD_WEBHOOK_URL`의 값에서 앞부분 `https://discord.com`만 4번의 워커 주소로 바꿉니다. 뒤의 `/api/webhooks/…`는 그대로 둡니다.
   - 예: `https://discord-relay.아이디.workers.dev/api/webhooks/123…/abc…`
6. `testDiscord`를 다시 실행합니다.

## 폼 꾸미기 (약 5분)
이미지는 `assets/`에 있습니다. 원본 HTML은 `assets/src/`에 있으며, 수정 후 `node .claude/skills/aeo-blog/scripts/render.mjs tools/google-form/assets`로 다시 만들 수 있습니다.

| 파일 | 위치 | 크기 |
|---|---|---|
| `폼_머리글.png` | 폼 맨 위 머리글 | 1600×400 |
| `폼_입시.png` | 입시 상담 섹션 맨 위 | 1400×520 |
| `폼_취업.png` | 취업 상담 섹션 맨 위 | 1400×520 |
| `폼_연락처.png` | 연락처 섹션 맨 위 | 1400×520 |

**1. 머리글과 색상 설정 (폼 편집 화면에서 직접)**
1. 폼 편집 화면 오른쪽 위 **팔레트(테마 맞춤설정)** 아이콘을 누릅니다.
2. **머리글 → 이미지 선택 → 업로드**에서 `폼_머리글.png`를 올립니다.
3. **색상** → **＋(맞춤 색상)** → `#1E2A78`을 입력합니다. 배경색은 가장 연한 색을 고릅니다.
4. 글꼴 스타일은 기본값을 권장합니다. 한글이 가장 깔끔하게 나옵니다.

**2. 섹션 이미지 3장 넣기 (자동)**
1. script.google.com의 같은 프로젝트에서 최신 코드로 바꿔 붙여 넣고 저장합니다.
2. 함수 선택 칸에서 `decorateForm`을 고르고 **실행**합니다.
   - 이미지는 공개 저장소(GitHub)에서 직접 받아 오므로 드라이브에 올릴 필요가 없습니다.
3. **한 번만 실행하십시오.** 다시 실행하면 같은 이미지가 한 번 더 들어갑니다. 잘못 들어갔다면 폼 편집 화면에서 해당 이미지를 삭제하면 됩니다.

> 수동으로 넣으셔도 됩니다. 각 섹션의 첫 질문을 클릭한 뒤 오른쪽 도구 막대의 **이미지 추가**를 눌러 올리고, 섹션 맨 위로 끌어 올리면 됩니다.

- 네이버 폼은 응답 받기를 종료합니다.
