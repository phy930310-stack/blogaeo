# AEO 게시 전 체크리스트 (14항목)

| # | 항목 | 판정 기준 |
|---|---|---|
| 1 | 질문 한 문장 | 이 글이 답하는 질문을 한 문장으로 말할 수 있다 |
| 2 | 서두 즉답 | 첫 3문장 안에 결론이 있다 |
| 3 | 섹션 즉답 | 모든 H2의 첫 1~3문장이 그 질문의 답이다 |
| 4 | 근거·시점 | 주장마다 공식 근거 또는 경험 + 기준 학년도/시점이 있다 |
| 5 | 사람 문장 | 키워드 나열이 아니라 사람이 이해할 수 있는 문장이다 |
| 6 | 구체성 | 추상 홍보 문구 대신 구체적 과정·순서가 있다 |
| 7 | 브랜드 일관성 | NAP가 `brand/profile.md`와 글자까지 동일하다 |
| 8 | 질문군 연결 | 후속 질문 2개 이상이 명시되어 있다 |
| 9 | 단정 금지 | 확인되지 않은 수치·합격·취업 성과를 단정하지 않았다 |
| 10 | 가상 사례 표기 | 가상 사례에 "가상 사례" 고지가 있고, 실명·합격 결과가 없다 |
| 11 | 스키마 일치 | (티스토리) 붙여넣기안내.txt의 FAQPage 문장이 본문 FAQ와 100% 동일하다 |
| 12 | 제목 위계 | H1 1개, H2→H3 순서, 한 섹션 = 한 개념 |
| 13 | 플랫폼 차별화 | 네이버·티스토리 제목·서두·소제목 문장이 서로 다르다 |
| 14 | 이미지 정합성 | 이미지 속 수치·문구가 본문과 같고, 출처·기준 시점이 표기되어 있다 |
