# AEO 블로그 자동 작성

근거 문서: `docs/01_AEO_리서치_요약.md`, `docs/02_자동화_파이프라인_개요.md`
브랜드 정보: `brand/profile.md` (빈칸은 추측으로 채우지 말고 `[확인 필요]`로 남긴다)

## 입력

- 필수: 키워드 (예: `게임학과 내신 5등급`)
- 선택: 플랫폼(`naver` | `tistory`, 기본값 `brand/profile.md`의 주 플랫폼), 메모, 실제 상담 사례, 참고 URL

## 절차

### 0. 준비
1. `brand/profile.md`, `templates/post-template.md`, `templates/checklist.md`를 읽는다.
2. 작업 폴더 `posts/YYYY-MM-DD_키워드-슬러그/`를 만든다.

### 1. 질문 변환 (키워드 → 질문군)
- 키워드를 잠재고객이 **실제로 검색하거나 AI에게 물을 법한 상황형 질문**으로 바꾼다.
- 산출: 핵심 질문 1개, 하위 질문 4~6개(검색 의도 단위), 후속 질문 2~3개.
- 하위 질문은 서로 겹치지 않게 하고, 핵심 질문의 답을 구성하는 순서로 정렬한다.
- 웹 검색으로 관련 질문(연관 검색어, 커뮤니티 질문)을 확인해 보강한다.

### 2. 리서치
- 각 하위 질문마다 공식 근거(대학 모집요강, 정부·기관 통계, 업계 공식 자료)를 찾는다.
- 모든 근거는 `출처명 / URL / 기준 시점 / 확인일`로 기록한다.
- 찾지 못했거나 연도가 지난 정보는 본문에 `[확인 필요: 사유]`로 표시한다. **수치를 지어내지 않는다.**

### 3. 개요
- `templates/post-template.md` 구조에 질문과 근거를 배치한다.
- 질문 성격에 맞는 블록 형식을 고른다: 정의형 → 정의 블록, 방법형 → 단계 목록, 비교형 → 표.

### 4. 본문 작성 규칙
- 제목: 질문형 핵심 질문 + `| 지역·브랜드 보조어`.
- 서두 3~5줄 안에 결론. 첫 문장이 곧 답이어야 한다.
- 모든 H2는 질문 그대로 쓰고, **답변 블록 4단계**를 따른다:
  1) 질문 소제목 → 2) 첫 1~3문장(80~150자) 직접 답변 → 3) 근거 + 기준 시점 → 4) 행동 방법 + 다음 질문 연결
- 한 문단 = 한 내용. 추상적 홍보 문구("체계적인 커리큘럼", "최고의 강사진") 대신 구체적 과정·순서를 쓴다.
- 브랜드 맥락(지역·과정·대상)은 H2 2~3곳에 자연스럽게만 넣는다. 키워드 반복 금지.
- 상담 사례: 사용자가 제공한 사례만 사용한다. 없으면 섹션에 `[상담 사례 입력 필요]` 안내만 남긴다. **사례·후기·합격/취업 실적을 창작하지 않는다.**
- 문체: 블로그 독자 대상 해요체 기본(브랜드 프로필 지정 시 그에 따름).

### 5. 기계 가독성 산출물
- `faq-schema.html`: 본문 FAQ 섹션의 질문·답변을 **토씨 하나까지 동일하게** FAQPage JSON-LD로 만든다(`templates/faq-schema.html` 참고). 플랫폼이 `naver`이면 생성은 하되 report에 "네이버는 삽입 불가, 홈페이지/티스토리용"이라고 적는다.
- 메타 설명(80자 내외, 즉답 문장 기반)과 태그 5~10개를 report에 적는다.

### 6. 자체 검수
- `templates/checklist.md` 12항목을 하나씩 점검해 report에 ✅/❌로 기록한다.
- ❌ 항목은 본문을 고친 뒤 다시 점검한다. 고칠 수 없는 항목(사실 확인 등)은 "사람 확인 필요"로 넘긴다.

### 7. 채널 파생 (사용자가 요청했거나 profile에서 켠 경우)
- `instagram.md`: 카드뉴스 첫 장 = 핵심 질문, 캡션 첫 문장 = 즉답, 이후 이유 → 방법, 마지막에 블로그 원문 안내.

## 출력

```
posts/YYYY-MM-DD_슬러그/
  post.md          발행용 본문
  faq-schema.html  FAQPage JSON-LD
  report.md        질문 지도, 출처 목록, 메타 설명·태그, 체크리스트 결과, 사람 확인 항목
  instagram.md     (선택)
```

마지막에 사용자에게 다음을 간단히 보고한다: 제목, 핵심 질문, 체크리스트 통과 수, `[확인 필요]` 항목 목록.
