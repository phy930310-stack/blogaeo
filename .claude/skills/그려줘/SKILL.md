# 그려줘 — 구독 계정 CLI로 이미지 생성

## 동작 순서
1. **요청 해석** — 사용자의 한국어 요청에서 아래 옵션을 읽는다.
   - 도구: "제미나이로"/"구글로"/"안티그래비티로" → `agy`, "코덱스로"/"GPT로"/"챗GPT로" → `codex`, "둘 다로"/"비교" → `both`. **지정 없으면 `agy`** (2026-10-19 기준 ChatGPT Free 계정은 Codex 내장 이미지 도구가 제공되지 않음)
   - 비율: "정사각형"(기본) → `square`, "세로" → `portrait`(3:4), "가로" → `landscape`(16:9)
2. **영어 프롬프트 작성** — 한 문단, 구체적으로: 주제·인물/사물, 행동·포즈, 화풍(예: clean cel-shaded 2D illustration), 색감·조명, 배경, 구도, 그리고 항상 `no text, no watermark`.
   - 학원 홍보용이면 밝고 친근한 톤. 실존 인물·실제 상표·로고·저작권 캐릭터를 흉내 내지 않는다.
   - 작성한 프롬프트를 사용자에게 한 줄로 보여 준다.
3. **생성** — 저장소 루트에서 실행:
   ```bash
   bash tools/image-cli/draw.sh --tool <agy|codex|both> --ratio <square|portrait|landscape> --prompt "<영어 프롬프트>"
   ```
   - 1~3분 걸린다. 출력의 `저장: ./images/...` 경로를 확인한다.
4. **결과 표시** — 저장된 PNG를 Read로 열어 확인하고 사용자에게 파일로 보낸다(비교 모드면 두 장을 함께).
   - 글자 깨짐·손가락 이상 등 문제가 보이면 그 사실을 말하고 프롬프트를 고쳐 1회까지 재생성을 제안한다.

## 실패했을 때
| 메시지 | 대응 |
|---|---|
| `미설치` | `bash tools/image-cli/setup.sh` 실행 후 재시도 |
| `[agy] 로그인 필요` | tmux로 `agy` 실행 → "Google OAuth" 선택 → 표시되는 주소를 사용자에게 전달 → 사용자가 준 인증 코드를 붙여넣기. 첫 실행 설정의 데이터 수집 동의는 사용자에게 묻는다(기본 권장: 해제) |
| `[codex] 로그인 필요` | `codex login --device-auth` → 주소·일회용 코드를 사용자에게 전달(ChatGPT 보안 설정에서 기기 코드 인증 허용 필요) |
| `[codex] 내장 이미지 도구가 제공되지 않습니다` | 요금제 문제로 추정. `agy`로 대신 생성할지 묻는다. **API 키 방식(fallback)은 사용하지 않는다** |
| `[agy] 구글 이미지 생성 한도 소진(429)` | 무료 계정 이미지 한도 소진. 사실대로 알리고 나중에 재시도(같은 날 연속 재시도 금지). Codex 가능하면 대안으로 제안 |
| `이미지가 만들어지지 않았습니다` | 같은 명령으로 1회 재시도, 그래도 안 되면 사실대로 보고 |

## 원칙
- API 키·`OPENAI_API_KEY`·`--dangerously-*` 옵션을 쓰지 않는다.
- 로그인 정보(`~/.codex/auth.json`, `~/.gemini/antigravity-cli/antigravity-oauth-token`)를 저장소에 커밋하거나 대화에 출력하지 않는다.
- `images/`는 git에서 제외되어 있다. 남겨야 할 이미지는 사용자에게 파일로 보내거나, 요청 시 글 폴더로 옮겨 커밋한다.
